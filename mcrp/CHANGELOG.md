# Changelog

## 0.0.1

- Translated all 22 exported computational routines from mcrp 0.0-1.
- Added centered second-, third-, and fourth-order co-moment calculations.
- Added raw and standardized moment derivatives and contribution decompositions.
- Added a self-contained bounded Nelder-Mead implementation for multiple-
  criteria risk-parity optimization.
- Added typed results, explicit status codes, examples, documentation, and
  independent numerical tests.
- Preserved GPL-3.0-only licensing, attribution, and the original source tree.
