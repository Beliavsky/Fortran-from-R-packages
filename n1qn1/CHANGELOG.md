# Changelog

## 0.1.0

- Initial modern Fortran translation of `n1qn1`, `n1qn1a`, and `majour`.
- Added typed objective, gradient, progress, control, and result APIs.
- Added dense-Hessian initialization and exact factor restart.
- Added Hessian packing/conversion helpers and R-compatible `c_hess` output.
- Added numerical regression tests, examples, documentation, and build scripts.
