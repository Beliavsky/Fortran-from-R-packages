# Changelog

## 0.12.0-fortran.1

- Initial modern Fortran/FPM translation of Dowd 0.12 computational routines.
- Added dependency-free normal, Student-t, chi-square, beta, and gamma tools.
- Added analytical, historical, EVT, kernel, bootstrap, portfolio, backtest,
  option, copula, insurance, bond, and pension modules.
- Added strict numerical tests, examples, attribution, and dual GPL license
  texts corresponding to the original package's unversioned `GPL` metadata.
- Documented deliberate corrections to inherited source defects.
