# Notice and attribution

This project is a modern Fortran translation of the computational routines in
**Dowd 0.12**, an R package by Dinesh Acharya that ports functions from Kevin
Dowd's *Measuring Market Risk* MMR2 MATLAB toolbox.

Original package metadata:

- Package: `Dowd`
- Version: `0.12`
- Date: `2015-08-20`
- Author and maintainer: Dinesh Acharya
- Original metadata license: `GPL`
- CRAN publication date: `2016-03-11`

The original `DESCRIPTION` and `NAMESPACE` files are retained under
`original_metadata/`. The Fortran translation is distributed under
`GPL-2.0-only OR GPL-3.0-only`; see `LICENSE` and `LICENSES/`.

The book and original toolbox remain the conceptual sources for many formulas:

Kevin Dowd, *Measuring Market Risk*, second edition, Wiley, 2007.

implied. This is an independent language port. The API is Fortran-oriented and
