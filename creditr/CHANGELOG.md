# Changelog

## 0.6.2-fortran.1

- Added modern Fortran/FPM translation of the `creditr` computational core.
- Added Gregorian date and business-day utilities.
- Added USD/EUR/JPY conventions and package-compatible date generation.
- Added money-market and par-swap zero-curve bootstrap.
- Added ISDA-style CDS fee and protection legs, flat-hazard calibration, and clean/dirty upfront pricing.
- Added spread/upfront conversion and risk sensitivities.
- Added CSV curve input, typed APIs, examples, tests, and reproducible build scripts.
- Retained the complete original package tree and both governing license texts.
