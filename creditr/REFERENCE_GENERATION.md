# Reference generation

The fixed CDS references were generated by compiling the original source under `original/creditr-main/src` as a standalone static C library and calling the same ISDA functions used by the Rcpp wrappers.

Representative market data are the USD curve for trade date 2014-04-15 retained in the original package tests. The curve base date is 2014-04-17 and the CDS maturity is 2019-06-20.
