# Notice

`argus-fortran` is a modern Fortran translation of the computational code in
the CRAN package `argus` version 0.1.1 by Wolfgang Hoermann and Christoph
Baumgarten.

The upstream package provides density, CDF, quantile, and random variate
generation for the Argus distribution. Its R interface depends on R and
Runuran. This port is standalone Fortran and does not require either.

The upstream files used as translation references are retained in
`upstream/` and remain subject to their original GPL (>= 2) terms.
