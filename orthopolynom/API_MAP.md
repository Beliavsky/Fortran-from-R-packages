# API map

R names are mapped to conventional underscore-separated Fortran names.

| R `orthopolynom` API | Fortran API |
|---|---|
| `*.inner.products` | `*_inner_products` |
| `*.recurrences` | `*_recurrences` |
| `*.polynomials` | `*_polynomials` |
| `*.weight` | `*_weight` |
| `jacobi.matrices` | `jacobi_matrices` |
| `lpochhammer` | `lpochhammer` |
| `pochhammer` | `pochhammer` |
| `monic.polynomial.recurrences` | `monic_polynomial_recurrences` |
| `monic.polynomials` | `monic_polynomials` |
| `orthogonal.polynomials` | `orthogonal_polynomials` |
| `orthonormal.polynomials` | `orthonormal_polynomials` |
| `polynomial.coefficients` | `polynomial_coefficients` |
| `polynomial.derivatives` | `polynomial_derivatives` |
| `polynomial.functions` | `polynomial_functions` |
| `polynomial.integrals` | `polynomial_integrals` |
| `polynomial.orders` | `polynomial_orders` |
| `polynomial.powers` | `polynomial_powers` |
| `polynomial.roots` | `polynomial_roots` |
| `polynomial.values` | `polynomial_values` |
| `scaleX` | `scale_x` |

The family prefixes map similarly, for example `jacobi.p.polynomials` to
`jacobi_p_polynomials` and `ghermite.h.weight` to `ghermite_h_weight`.
