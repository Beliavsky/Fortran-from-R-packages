# Changelog

## 0.1.0

- Initial modern Fortran 2018 computational translation of waveslim 1.8.5.
- Added FPM and GNU Make builds, seven tests, examples, API mapping, and
  validation documentation.
- Added 1-D/2-D/3-D DWT and MODWT, packet, dual-tree, Hilbert, denoising,
  statistics, long-memory, bootstrap, and variance-change functionality.
- Preserved the BSD 3-Clause license and complete upstream source provenance.
