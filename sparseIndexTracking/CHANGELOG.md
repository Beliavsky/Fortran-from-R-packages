# Changelog

## 0.1.0 - 2026-08-03

- Initial modern Fortran translation of sparseIndexTracking 0.1.1.
- Added ETE, DR, HETE, and HDR sparse tracking estimators.
- Added capped-simplex projection and deterministic largest-eigenvalue solver.
- Added typed and compatibility APIs, tests, example, FPM manifest, and Makefile.
- Added corrected elementwise HDR objective with optional source-compatible mode.
- Preserved the upstream source and GPL-3 license.
