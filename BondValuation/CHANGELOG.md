# Changelog

## 0.1.1-fortran.1

- Translated the complete computational core to modern Fortran.
- Added all sixteen day-count conventions and the exact Brazilian calendar.
- Added regular, odd-coupon, and zero-coupon schedule construction.
- Added accrued interest, clean/dirty pricing, YTM, durations, and convexity.
- Added original-name and low-level compatibility APIs.
- Replaced R/Rcpp/timeDate infrastructure with typed Fortran structures.
- Added FPM packaging, examples, independent numerical tests, and documentation.
