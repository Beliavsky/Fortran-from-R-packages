# Changelog

## 0.1.0

- Added all 12 adaptive Gauss-Kronrod rules.
- Added finite and infinite one-dimensional integration.
- Added native Cuhre rules 13, 11, and 9 with adaptive region subdivision.
- Added L-BFGS and L-BFGS-B wrapper APIs.
- Added native `fast_lr` logistic regression.
- Added tests, examples, FPM metadata, provenance, and license notices.
- Corrected the 121-point Gauss-rule center handling.
- Corrected the Jacobian for finite dimensions in mixed finite/infinite
  multidimensional integrals.
