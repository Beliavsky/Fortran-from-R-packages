# Notice and attribution

This project is a modified-language port of the computational portions of the
R package `riskParityPortfolio` 0.2.2.9000.

Original package authors:

- Ze Vinicius
- Daniel P. Palomar

The original package cites the following principal methods:

- Y. Feng and D. P. Palomar (2015), SCRIP: Successive Convex Optimization
  Methods for Risk Parity Portfolio Design, IEEE Transactions on Signal
  Processing 63(19), 5285-5300.
- F. Spinu (2013), An Algorithm for Computing Risk Parity Weights.
- T. Griveau-Billion, J. Richard, and T. Roncalli (2013), A Fast Algorithm for
  Computing High-Dimensional Risk Parity Portfolios.

Original metadata and computational source files are included in `original/`.
The Fortran files identify the original work and the applicable license in
source headers.
