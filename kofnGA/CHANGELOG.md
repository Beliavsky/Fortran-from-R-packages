# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of kofnGA 1.3.
- Added callback-based fixed-size subset GA.
- Added rank-weighted tournaments, union crossover, fixed-cardinality mutation,
  elitism, initial-population continuation, histories, and summary support.
- Added compiler-independent Park-Miller RNG state.
- Omitted R plotting/S3 and parallel/shared-memory dispatch infrastructure.
