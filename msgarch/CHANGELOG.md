# Changelog

## 0.1.0

- Initial combined modern Fortran translation of the MSGARCH computational core.
- Added five conditional-volatility recursion families.
- Added six standardized innovation distributions, including Fernandez-Steele skewing.
- Added single-regime, Markov-switching, and static-mixture specifications.
- Added Hamilton filtering, smoothing, Viterbi decoding, simulation, forecasting, PIT, predictive density, and risk calculations.
- Added bounded ML estimation, numerical Hessians/covariances, fixed parameters, and regime-constant parameter groups.
- Added adaptive random-walk MCMC, DIC, posterior averaging, and homogeneous-regime relabeling.
- Added Gaussian HMM and Gaussian mixture EM utilities.
- Added variance targeting, unconditional-volatility simulation, and multi-step KDE predictive distributions.
- Added strict debug/release build scripts, license checks, tests, examples, and CSV fitting.
