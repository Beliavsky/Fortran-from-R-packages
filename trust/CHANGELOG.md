# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `trust` 0.1-9.
- Ported the eigendecomposition-based trust-region algorithm.
- Added self-contained symmetric Jacobi eigensolver and secular-equation bisection.
- Added typed objective callback and derived-type controls/results/history.
- Added minimization, maximization, `parscale`, restricted-domain handling, and all upstream step classifications.
- Added seven strict regression programs and two examples.
