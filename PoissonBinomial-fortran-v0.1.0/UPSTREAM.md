# Upstream source and license

This project is a modern Fortran translation of the computational code in the
R package **PoissonBinomial 1.2.8**.

Upstream package metadata:

- Package: `PoissonBinomial`
- Version: 1.2.8
- Date: 2026-03-06
- Author/Maintainer: Florian Junge
- Upstream repository: `https://github.com/fj86/PoissonBinomial`
- Upstream license: GPL-3

The original package's `DESCRIPTION`, `NAMESPACE`, and `NEWS.md` are retained
under `upstream/`. The complete GNU GPL version 3 license text is retained as
`LICENSE`.

The statistical methods implemented upstream cite:

- Hong, Y. (2013), *Computational Statistics & Data Analysis* 59, 41-51.
- Biscarri, W., Zhao, S. D. and Brunner, R. J. (2018),
  *Computational Statistics and Data Analysis* 31, 216-222.
- Zhang, M., Hong, Y. and Balakrishnan, N. (2018),
  *Journal of Statistical Computation and Simulation* 88(8), 1515-1527.

This translation is distributed under the same GPL-3.0-only terms.
