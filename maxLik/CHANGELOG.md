# Changelog

## 1.5.2-fortran.1

- Initial modern Fortran/FPM translation of the computational core of maxLik
  1.5-2.2.
- Added common callback, control, result, and status interfaces.
- Added NR, BFGS/BFGSR, BHHH, CG, Nelder-Mead, simulated annealing, SGA, and
  Adam maximizers.
- Added numerical derivatives, vector Jacobians, derivative checking, fixed
  parameters, bounds, linear constraints, inference, and diagnostics.
- Added six regression programs, five examples, a demonstration program, build
  scripts, documentation, license texts, and the retained upstream snapshot.
