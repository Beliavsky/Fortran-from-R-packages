# Changelog

## 2.1.8-fortran.1

- Initial modern Fortran/FPM translation of the computational core of R
  `cluster` 2.1.8.3.
- Added typed implementations of DAISY, PAM, CLARA, FANNY, AGNES, DIANA, MONA,
  silhouette widths, gap statistics, medoid helpers, and ellipsoid geometry.
- Added strict and optimized tests, examples, a demo, documentation, and the
  retained upstream package snapshot.
