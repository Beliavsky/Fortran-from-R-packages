# Changelog

## 0.1.0

- Initial modern Fortran computational translation of garchx 1.7.
- Added sparse-lag ARCH, GARCH, asymmetry, and covariate recursion.
- Added simulation, filtering, derivatives, QML fitting, and likelihoods.
- Added ordinary, robust, and HAC coefficient covariance calculations.
- Added bootstrap forecasts, conditional quantiles, and refitting.
- Added asymptotic covariance simulation and boundary-null inference.
- Added vector/matrix lagging and differencing and multivariate Normal RNG.
- Added demo, sparse-lag example, dated CSV application, and three test suites.
- Added machine-checked GPL-2.0-or-later headers and provenance documentation.
