# Validation

## Included deterministic tests

- `test/test_r_reference.f90`: frozen actual-R ineq 0.2-13 oracle checks,
  generated by `validation/generate_reference.R`.
- `test/test_identities.f90`: independent numerical identities, parameter limits,
  600-order scale range, extreme income-frequency multiplication, and regressions.
- `test/test_support.f90`: IEEE-aware assertions; NaN and infinity are compared
  explicitly and finite comparisons use documented relative/absolute tolerances.
- `example/inequality_demo.f90`: complete standalone example covering inequality,
  poverty, an empirical curve and a theoretical curve.

Reference generation was executed using the exact installed upstream version;
R runtime/session evidence and the raw 17-digit oracle are included under
`validation/`. FPM builds/tests do not depend on R, Python, or a network connection.
The tests exercise every declared function mapping.

## Release verification commands

Run each profile's build, test, and all examples:

```sh
fpm build
fpm test
fpm run --example --all
fpm build --profile debug --flag '-O0 -g -fcheck=all -fbacktrace -Wall -Wextra -Wimplicit-interface -fimplicit-none'
fpm test --profile debug --flag '-O0 -g -fcheck=all -fbacktrace -Wall -Wextra -Wimplicit-interface -fimplicit-none'
fpm run --example --all --profile debug --flag '-O0 -g -fcheck=all -fbacktrace -Wall -Wextra -Wimplicit-interface -fimplicit-none'
fpm build --profile release
fpm test --profile release
fpm run --example --all --profile release
```

The quoted flag string syntax above is suitable for common shells; adjust quoting
for the Windows shell in use. Do not add fast-math flags. Expected invalid powers,
log zero, and zero denominators deliberately exercise IEEE NaN/infinity behavior.
Do not add floating-point exception traps for these regression tests.

Before distributing, also verify function-coverage metadata, retained upstream
file hashes, dependency reuse, no duplicate Fortran sources, FORD dummy comments,
free-form style/single kind, no self-comparison NaN tests or semicolon-separated
statements in maintained source, then run `fpm clean --all`. No compiled outputs,
module files, caches, dependency copies, or ZIP files belong inside the package.

Native Windows execution has not been verified. The sources and FPM sibling-path
dependency require no POSIX runtime, shell execution, or external BLAS/LAPACK.

## Verified result, 2026-10-12

All nine owner stages above passed on the unchanged numerical source and tests:
GNU Fortran 14.2.0 (Debian 14.2.0-19), FPM 0.13.0 alpha, Linux. Each test stage
reported 966 actual-R reference assertions and 477 independent assertions.
Both the default and release example printed finite inequality/poverty values
and Lorenz coordinates with the expected endpoints. Runtime-checked debug passed
with array/bounds checking and explicit-interface diagnostics enabled.

The full-prompt static audit found no errors or warnings: eight maintained
free-form Fortran files and 99 dummy arguments each individually declared with
INTENT and a meaningful trailing FORD comment. Real-comparison compiler warnings
are expected for exact upstream branch conditions, missing/special-value tests,
and the no-tolerance majorization contract. Shared dependency source was unchanged.

Independent review additionally compared 323 weighted Lorenz/Mehran/asymmetry
reference rows, a 234-case scalar grid, and a theoretical tail grid against R.
It identified original-arithmetic tie regressions in majorization, mean-asymmetry
intervals and Mehran slopes; those were corrected and regression-tested before
the final owner build matrix. The review's remaining differences were documented
special-value/domain policies and numerical stabilization improvements.
