# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of BenfordTests 1.2.0.
- Ported all exported computational test statistics and support functions.
- Ported the C null-simulation kernels to native Fortran.
- Ported the numerical part of `signifd.analysis`; plotting omitted.
- Added self-contained normal, chi-square-tail, and symmetric-eigenvalue numerical support.
- Added strict regression tests and a basic example.
