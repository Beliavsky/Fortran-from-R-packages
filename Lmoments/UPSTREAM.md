# Upstream sources

- `upstream/Lmoments-master.zip`: exact user-supplied R package source used for this translation (DESCRIPTION version 1.3-2, dated 2025-09-17).
- `upstream/lmoments-3.04-original.f`: exact user-supplied concatenated J. R. M. Hosking LMOMENTS Version 3.04 source (July 2005).

The R package is the behavioral/API source. Hosking's original Fortran is used as an algorithmic/reference source where it overlaps the package's L-moment computations and normal quantile support.
