# Upstream provenance

Source archive: `nnls-master.zip`

R package metadata:

- Package: `nnls`
- Version: `1.6`
- Authors: Katharine M. Mullen and Ivo H. M. van Stokkum
- Package license: GPL (>= 2), represented here as GPL-2.0-or-later

The package's `inst/COPYRIGHTS` states that the NNLS source derives from the
public-domain Lawson-Hanson code distributed with *Solving Least Squares
Problems* and obtained from Netlib. The NNNPLS source is that code with small
modifications for mixed nonnegative/nonpositive constraints.

The complete supplied package is retained under `original/nnls-master/`, and
its `inst/COPYRIGHTS` is copied to the release root as `COPYRIGHTS`.
