# Changelog

## 1.3.0-fortran.1

- Added modern Fortran 2018 implementation of `hclust` and `hclust.vector`.
- Added all eight distance-matrix linkage methods.
- Added all six single-linkage vector metrics.
- Added Ward, centroid, and median vector clustering.
- Added R-compatible condensed distance conversion and merge numbering.
- Added explicit status handling, tests, examples, documentation, and FPM
  packaging.
- Retained upstream sources and dual-license information.
