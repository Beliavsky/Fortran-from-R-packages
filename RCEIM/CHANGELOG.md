# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of RCEIM 0.3 computational code.
- Added CE-inspired optimizer with minimization/maximization, elite/super members, smoothing, chaos generation, stopping rules, bounds clipping, and histories.
- Added direct translations of both benchmark functions.
- Added portable RNG helpers, tests, examples, and strict GNU Fortran validation scripts.
- Preserved GPL-2.0-or-later licensing and complete upstream source provenance.
