# optimx-fortran

A modern Fortran/FPM translation of the computational core of R package
`optimx` 2025-4.9.

The library provides a common typed interface to several smooth optimization
methods, bounds and fixed-parameter masks, numerical derivatives, derivative
checks, KKT diagnostics, multistart optimization, and sequential
polyalgorithm optimization.

## Implemented solver families

- Nash/Fletcher variable metric (`Rvmmin`, `Rvmminu`, `Rvmminb`)
- Nonlinear conjugate gradient (`Rcgmin`, `Rcgminu`, `Rcgminb`, `ncg`)
- Variable metric (`nvm`)
- Hooke-Jeeves (`hjn`)
- Nelder-Mead through `optimr`
- Safeguarded Newton (`snewton`, `snewtm`)
- Truncated-Newton-compatible entry points (`tn`, `tnbc`)
- Multi-method `opm`/`optimx`, `multistart`, and `polyopt`

The Fortran callback can provide only objective values, objective and gradient,
or objective, gradient, and Hessian. Missing derivatives are generated by
finite differences.

## Build

```text
fpm build
fpm test
fpm run --example rosenbrock_methods
fpm run demo_optimx
```

The project has no external FPM dependencies.

## Minimal use

```fortran
use optimx_mod
use optimx_example_functions, only: rosenbrock_callback

type(optimx_problem) :: problem
type(optimx_result) :: answer

call initialize_problem(problem, 2)
problem%objective => rosenbrock_callback
problem%has_gradient = .true.
problem%has_hessian = .true.
call optimr(problem, [-1.2_dp, 1.0_dp], 'Rvmmin', result=answer)
```

See `API.md` and `PORTING.md` for callback details and method mappings.
