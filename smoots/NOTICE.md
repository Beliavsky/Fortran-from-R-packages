# Notice and attribution

This project is a modern Fortran translation of the computational algorithms in the R package `smoots` 1.1.4.

Original package authors listed in `DESCRIPTION`:

- Yuanhua Feng
- Sebastian Letmathe
- Dominik Schulz
- Thomas Gries
- Marlon Fritz

The original package is licensed under GPL-3. The original source and package metadata are retained in `original/`.

Principal methodological reference:

Y. Feng, T. Gries, and M. Fritz (2020), "Data-driven local polynomial for the trend and its derivatives in economic time series," Journal of Nonparametric Statistics 32(2), 510-533.

This translation is not an official release of the original authors.
