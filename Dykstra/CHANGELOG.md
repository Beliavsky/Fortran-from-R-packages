# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of Dykstra 1.0-0.
- Ported cyclic projection QP solver, equality/inequality constraints,
  factorized input, diagonal fast path, PSD regularization, and result
  bookkeeping.
- Added a standalone symmetric Jacobi eigensolver.
- Added five regression tests and two examples.
- Added strict GNU Fortran validation scripts.
