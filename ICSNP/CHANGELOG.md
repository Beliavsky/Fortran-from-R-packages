# Changelog

## 1.1.3-fortran.1

- Translated all 20 exported computational routines from ICSNP 1.1-3.
- Added self-contained dense linear algebra and distribution functions.
- Replaced the external R `ICS` dependency with a FOBI-style invariant
  coordinate transform.
- Added deterministic simulation/permutation support.
- Added four tests, three examples, one demo, FPM metadata, and documentation.
- Preserved GPL-2.0-or-later licensing and original computational sources.
