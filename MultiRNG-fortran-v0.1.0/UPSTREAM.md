# Upstream provenance

This project is a modern Fortran translation of the R package **MultiRNG 1.2.4**.

Upstream metadata from `DESCRIPTION`:

- Package: MultiRNG
- Version: 1.2.4
- Date: 2021-03-05
- Authors: Hakan Demirtas, Rawan Allozi, Ran Gao
- Maintainer: Ran Gao
- License: GPL-2 | GPL-3
- NeedsCompilation: no

The complete uploaded upstream package is retained in:

    upstream/MultiRNG-master/

The package describes pseudo-random generation for multivariate Normal, t, Uniform,
Bernoulli, Hypergeometric, Dirichlet, Multinomial, Dirichlet-Multinomial, Laplace,
Wishart, and Inverted-Wishart distributions.

Primary method reference cited upstream:

H. Demirtas (2004), multivariate pseudo-random number generation,
Journal of Modern Applied Statistical Methods, DOI 10.22237/jmasm/1099268340.

The correlated-binary routine cites Park, Park, and Shin (1996),
"A simple method for generating correlated binary variates",
The American Statistician 50(4), 306-310.
