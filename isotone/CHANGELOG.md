# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of isotone 1.1-2.
- Added generalized PAVA with three block solvers and all tie modes.
- Added repeated-measurement PAVA.
- Added primal active-set optimization and all predefined loss families.
- Added callback-driven custom differentiable loss support.
- Added `mregnn`, monotone and positive restricted regression using the
  supplied NNLS translation.
- Added strict runtime/interface tests and randomized external validation.
