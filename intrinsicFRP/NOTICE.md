# Notice

This project is a modern Fortran translation of `intrinsicFRP` 2.1.0 by Alberto
Quaini. The original project is available under GPL version 3 or later. Original
metadata and computational R/C++ sources are retained in `original/`.

The translation is not an official release of the upstream project. It replaces
RcppArmadillo, `glmnet`, R object infrastructure, and selected statistical
kernels with self-contained Fortran implementations. Important numerical
adaptations are described in `PORTING.md`.

Copyright and authorship notices in the original sources remain in force.
