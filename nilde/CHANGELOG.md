# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of nilde 1.1-7.
- Added reusable int64 Diophantine enumeration.
- Added additive partitions, subset sum and knapsack APIs.
- Added exact canonical one-dimensional bin packing.
- Added self-contained assignment lower bound and exact TSP solver.
- Preserved the original unbounded-knapsack return-value quirk behind a
  compatibility default, with a corrected maximization option.
- Added five regression executables and two examples.
- Retained complete original package sources and GPL provenance.
