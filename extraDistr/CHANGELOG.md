# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of extraDistr 1.10.0.5.
- Added all 194 exported numerical procedure names.
- Added 57 continuous, discrete, mixture, and multivariate distribution
  families.
- Added a self-contained probability/special-function kernel and seeded RNG.
- Added source-compatible and corrected modes for three upstream edge cases.
- Added FPM and Make builds, example program, five tests, provenance files, and
  validation documentation.
