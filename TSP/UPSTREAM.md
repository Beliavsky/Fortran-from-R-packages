# Upstream provenance

This project is a modern Fortran translation of the computational code in:

- **TSP: Infrastructure for the Traveling Salesperson Problem**
- Upstream version: **1.2.7**
- Upstream date: **2026-03-22**
- Authors/copyright holders: **Michael Hahsler and Kurt Hornik**
- Upstream project: `mhahsler/TSP`

The upstream `DESCRIPTION` declares `License: GPL-3`. Individual historical
source headers also state GNU GPL version 2 or later. This translation is
released under GPL-3.0-only to match the package metadata. The complete GPLv3
text is in `COPYING`. The original package metadata and citation file are
retained under `upstream/`.

The Fortran implementation was derived from the R and C computational routines
in the supplied source archive. It does not copy or bundle Concorde or
Chained-Lin-Kernighan; upstream itself only contains interfaces to those
separately distributed executables.
