# Changelog

## 0.2.0-fortran.1

- Added a complete FPM project for the bayesianOU computational workflow.
- Added single-, two-, and three-level OU model equations and simulation.
- Added native preprocessing, conditional initialization, hierarchy shrinkage,
  stochastic-volatility filtering, and blocked Metropolis fitting.
- Added Euclidean and SoftAbs Riemannian static HMC.
- Added PSIS-style LOO, OOS metrics, MCMC diagnostics, kappa stability, model
  comparison, and Rubin multiple-imputation pooling.
- Added numerical replacements for the data underlying the package plots.
- Retained the original package tree and MIT license for provenance.
- Added strict and optimized GNU Fortran builds, seven tests, one application,
  and two examples.
