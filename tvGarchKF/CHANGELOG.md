# Changelog

## 0.1.0 - 2026-08-04

- Initial modern Fortran/FPM computational translation of tvGarchKF 0.0.1.
- Added typed parameter-path, model, filter, fit, simulation, and rolling-fit APIs.
- Ported the native Kalman recursion and source criterion.
- Added IEEE-NaN missing handling and forecast periods.
- Added optional corrected GARCH constraints.
- Integrated the supplied GPL-compatible fGarch Fortran translation.
- Added five checked/optimized tests, demonstration, build scripts, and documentation.
