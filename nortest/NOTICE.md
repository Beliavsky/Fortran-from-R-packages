This package translates the numerical operations of **nortest 1.0-4**,
"Tests for Normality", released by CRAN on 2015-07-30.

Original authors:

- Juergen Gross, author; gross@statistik.tu-dortmund.de
- Uwe Ligges, author and maintainer; ligges@statistik.tu-dortmund.de

The original manuals attribute the test implementations to Juergen Gross.
The upstream DESCRIPTION declares **GPL (>= 2)**. The translated code and
package-authored examples/tests/documentation are distributed under
**GPL-2.0-or-later**, with the full GPL version 2 in `LICENSE`. No separate
copyright notice was found in the upstream R source headers; the authorship
and all available original metadata, change history, sources, and manual
notices are retained without alteration under `upstream/`.

Upstream locations and pinned source:

- CRAN: https://cran.r-project.org/package=nortest
- CRAN mirror repository: https://github.com/cran/nortest

- Upstream package date: `2015-07-29`
- Source files: `upstream/R/{ad,cvm,lillie,pearson,sf}.test.R`
- SHA-256 checksums of the retained source snapshot: `upstream/SHA256SUMS`

Fortran translation prepared 2026-10-11. The translation preserves the
original formulas and calibration coefficients while replacing R objects and
conditions with a pure Fortran derived result type and status codes. See
`API_COVERAGE.md` for documented differences. Deterministic reference values
were generated by sourcing the retained original R functions using GNU R
4.5.0; the generation script and frozen results are included under `test/`.

## Shared dependency

`rfortran-core` is used as the sibling FPM path dependency `../rfortran-core`.
The tested repository revision was
`cbd437d6d92f5481706fd8ea5a7829aaff7b6e24` of
https://github.com/Beliavsky/Fortran-from-R-packages.
Its named real kind, descriptive statistics, ordering, and distribution APIs
are reused rather than copied. That package retains its own MIT license and
notices (Vivek Rao and contributors). No dependency sources, BLAS, LAPACK,
ARPACK, or R runtime code are included in this package.

No warranty is provided; see `LICENSE`. These are numerical approximations
