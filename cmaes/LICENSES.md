# Licensing and provenance

## Original R package

The attached source is `cmaes` version 1.0-12. Its `DESCRIPTION` declares:

```text
License: GPL-2
```

The original authors listed there are Heike Trautmann, Olaf Mersmann, and
David Arnu. The R source states that the CMA-ES code is based on
`purecmaes.m` by N. Hansen and cites Hansen (2006), *The CMA Evolution
Strategy: A Comparing Review*.

The complete attached package is retained, unmodified, beneath
`original/cmaes-master/` for provenance.
