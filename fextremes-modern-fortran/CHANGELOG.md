# Changelog

## 0.1.0

- Initial modern Fortran translation.
- Added GEV/Gumbel and GPD probability, simulation, moment, PWM, and MLE paths.
- Added observed/expected inference and residual transforms.
- Added numeric block maxima, thresholds, point processes, and declustering.
- Added four extremal-index estimators and both original simulation models.
- Added empirical tail diagnostics, record statistics, exceedance ACFs, and
  Pickands/Hill/DEH tail-index estimators.
- Added GPD risk measures, profile intervals, tail curves, and threshold
  stability calculations.
- Added GEV return levels and profile-likelihood intervals.
- Added sample VaR/CVaR, EMA, RiskMetrics volatility, CSV applications, strict
  test suites, and GPL header checks.
