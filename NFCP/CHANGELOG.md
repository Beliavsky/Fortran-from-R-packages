# Changelog

## 0.1.0

- Initial modern Fortran 2018 computational translation of NFCP 1.2.2.
- Added N-factor model types, parameter packing, domains, Kalman filtering,
  forecasting, simulation, volatility diagnostics, option valuation, futures
  stitching, and bounded global/local MLE.
- Bundled the previously translated L-BFGS-B 3.0 package as a local dependency.
- Added checked and optimized tests, examples, provenance, and API documentation.
