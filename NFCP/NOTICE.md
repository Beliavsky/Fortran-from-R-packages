# Notices

This package is a modern Fortran computational translation of the R package
**NFCP 1.2.2**, authored by Thomas Aspinall, Adrian Gepp, Geoff Harris,
Simone Kelly, Colette Southam, and Bruce Vanstone.

The NFCP translation is distributed under GPL-3.0-only, matching the supplied
R package. The complete original R sources, documentation, vignette, and data
archive are retained under `original/NFCP-master` for attribution and
traceability.

The local `dependencies/lbfgsb3` package is the previously translated
L-BFGS-B 3.0 wrapper. Its wrapper code is GPL-2.0-only and its numerical
L-BFGS-B kernel retains the original modified BSD notice. See that package's
`LICENSE`, `NOTICE.md`, and `LICENSES` directory.
