# Notices and provenance

This project is a modern Fortran translation of computational routines from
**LearnBayes 2.15.2**, originally authored and maintained by Jim Albert.

The upstream R package declares `GPL (>= 2)`. This translation is therefore
distributed under **GPL-2.0-or-later**. See `LICENSE` for the GNU General Public
License version 2 text, and `upstream/LearnBayes-2.15.2/` for the complete
upstream snapshot retained for attribution and parity review.

The translated implementation is a derivative work. Names of upstream routines
are retained where useful for correspondence with the R package; this project
is not an official release of the upstream LearnBayes package.
