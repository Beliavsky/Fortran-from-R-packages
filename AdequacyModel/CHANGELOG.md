# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of AdequacyModel 2.0.0.
- Added descriptive statistics and numerical TTT curve.
- Added corrected particle swarm optimizer.
- Added native BFGS, Nelder-Mead, conjugate-gradient, and simulated-annealing optimizers.
- Added goodness-of-fit statistics, model-selection criteria, MLE support, and standard errors.
- Added finite/semi-infinite/infinite PDF integration checks.
- Added exact finite-sample KS p-values with asymptotic fallback.
- Added strict numerical and optimizer tests.
