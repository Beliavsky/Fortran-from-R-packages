# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational port of mlrMBO 1.1.6.
- Added DiceKriging-backed Gaussian-process surrogates.
- Added all built-in scalar infill criteria.
- Added focus-search optimization and proposed-point filtering.
- Added constant-liar and parallel-CB batch proposals.
- Added DIB/SMS/epsilon, ParEGO and native MSPOT-style multi-objective search.
- Added mixed parameter repair, conditional categorical parameters,
  optimization paths, continuation and termination.
- Added exact arbitrary-dimensional hypervolume and Pareto utilities.
- Omitted plotting, R object plumbing and external learner/optimizer adapters.
