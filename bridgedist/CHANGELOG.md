# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of bridgedist 0.1.3.
- Added elemental density, CDF, quantile, and inversion RNG routines.
- Added R-style vector recycling helpers.
- Added analytic mean/variance helpers from the package documentation.
- Added overflow-resistant density/CDF and cancellation-resistant upper-tail evaluation.
- Added strict numerical/reference, identity, option, vector, RNG, and tail tests.
