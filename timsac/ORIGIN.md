# Origin and provenance

- Original package: `timsac`
- Original version: 1.3.8-6
- Package title: Time Series Analysis and Control Package
- Original copyright holder: The Institute of Statistical Mathematics
- Original package license declaration: `GPL (>= 2)`
- Fortran port status: independent, experimental modern Fortran port
- Modification record: converted and modified for this project by 2026-07-23

The project converts the original fixed-form Fortran numerical core to
free-form Fortran and adds modern modules, allocation-safe interfaces, fpm and
Makefile builds, tests, tools, and an example. It also directly translates the
R-level `mfilter` computation. R interfaces, allocation, printing, and plotting
code are omitted.

The original authors and copyright holders retain copyright in their work.
The converted and newly written files are distributed under
GPL-2.0-or-later, consistent with the original package declaration.

The following original metadata and notices are retained under `reference/`:

- `DESCRIPTION`
- `COPYRIGHTS`
- `NAMESPACE`
- `NEWS.md`

Legacy source comments naming original designers, programmers, publications,
and revision dates have been retained during conversion.
