# Changelog

## 1.0.0

- Initial modern Fortran/FPM translation of corpmetrics 1.0.
- Translated all seven exported computational functions.
- Added typed result structures and explicit status codes.
- Added self-contained NPV and bracketed IRR routines.
- Added safe zero-rate loan handling and R-style two-decimal rounding.
- Added applications, examples, fixed-reference tests, documentation, license
  texts, and original-source provenance.
