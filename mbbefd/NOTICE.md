# Notice

This is an independent modern-Fortran computational translation of the R
package `mbbefd` 0.8.14 by Christophe Dutang and contributors.

The original package source is preserved unchanged in
`upstream/mbbefd-master/` for provenance. The Fortran dependency translations
supplied by the user are preserved in `vendor/` and retain their own authorship,
license, and provenance files.

This port is not the upstream R package and does not require R, Rcpp, MASS, or
R graphics at runtime. Plotting and S3 presentation infrastructure are not
translated.
