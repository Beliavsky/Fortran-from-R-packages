# Provenance files

- `LSMonteCarlo-master.zip` is the source archive supplied for translation.
- `SOURCE_ARCHIVE_SHA256.txt` records its SHA-256 checksum.
- `ORIGINAL_FILES_SHA256.txt` records every file retained under
  `original/LSMonteCarlo-1.0`.
- `TRANSLATED_FILES_SHA256.txt` records release files outside `original` and
  excludes checksum manifests and the retained binary source archive.
