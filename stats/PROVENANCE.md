# Provenance

Unweighted quantile types 1 through 9 use a shared implementation of the
Hyndman-Fan order-statistic definitions in `rfortran-core/r_quantiles`.
The installed R `quantile.default` behavior was inspected for discontinuity
rounding and infinite-endpoint conventions; no R implementation is bundled.
`reference/quantile_reference.R` generates deterministic numerical fixtures.
The existing shared type-7 entry point is unchanged for other consumers.

Serial-correlation diagnostics independently combine the shared sample ACF
with the standard Box-Pierce and Ljung-Box formulas. Upper-tail chi-square
probabilities use `rfortran-core`. Installed R supplies fixtures at several
lag counts with and without fitted-parameter adjustments in
`reference/diagnostics_reference.R`.

The `oneway_test` adapter reuses ordinary one-way ANOVA for pooled inference
and independently implements Welch's inverse-variance weighting and
approximate F degrees of freedom. Installed R supplies the numerical fixtures
in `reference/oneway_reference.R`, including unequal group sizes and a
configurable equal-variance assumption.

Fligner-Killeen testing is independently implemented from its median-centered
normal-rank-score definition. Median calculation, average ranks, normal
quantiles, and chi-square probabilities delegate to existing shared modules.
Installed R generates fixtures for tied deviations, unequal sample sizes,
singleton groups, and the undefined zero-score-variance case through
`reference/scale_tests_reference.R`.

McNemar's matrix interface independently sums the standard squared differences
of opposite off-diagonal cells divided by their totals. Installed R output
was consulted to verify the two-category continuity correction and undefined
zero-total behavior. Integer, fractional, and larger tables have deterministic
fixtures in `reference/mcnemar_reference.R`.

The multiple-testing module independently implements the standard step-down,
step-up, and multiplicative adjustment formulas, reusing `r_order` from
`rfortran-core`. The R `p.adjust` API and executable reference output were used
to verify method names, missing-value behavior, and total hypothesis counts.
No R implementation code is included in this module. Reference source:
[`p.adjust.R`](https://github.com/wch/r-source/blob/trunk/src/library/stats/R/p.adjust.R).

Hommel adjustment independently evaluates closed Simes tests: for each subset
size and target hypothesis, the least significant subset contains the largest
remaining probabilities. These subsets suffice because the local test is
monotone in each probability. This gives quadratic runtime without enumerating
all subsets. R fixtures verify ties, missing entries, and additional hypotheses.

The initial linear-model implementation was adapted on 2026-09-12 from:

- project: [`Beliavsky/R-to-Fortran`](https://github.com/Beliavsky/R-to-Fortran);
- file: `src/r_mod.f90`;
- revision: `6c930904ea2517703550ff73ebb5a4f3c6b867aa`; and
- source license: MIT, copyright 2026 Beliavsky.

The extracted code was reorganized into focused modules. Its local
normal-equation solver and hard-coded 95% Student-t critical-value table were
replaced by the shared `rfortran-linalg` and `rfortran-core` APIs.

The descriptive-statistics facade delegates means, variances, covariance and
correlation matrices, quantiles, and ordering to the MIT-licensed
`rfortran-core` package. It adds only `stats`-style generic adapters and the
short compositions needed for IQR and MAD, avoiding duplicate numerical code.

The ECDF and histogram routines use independently implemented sorting and bin
definitions matching the documented R conventions. Kernel density estimation
uses direct kernel summation rather than copying R's FFT implementation; its
Gaussian results are checked both against the mathematical kernel sum and
against R's interpolated FFT output. Bandwidth selectors reproduce the public
R formulas.

Linear and constant interpolation independently implement the behavior
documented for `approx`, including mean aggregation of tied predictors and
endpoint rules. The isotonic regression routine is an independent weighted
pool-adjacent-violators implementation. Both are checked against deterministic
R 4.6.0 output; no R source code was copied.

The cubic interpolation implementation expresses the documented natural and
Forsythe-Malcolm-Moler endpoint equations as a dense linear system solved by
`rfortran-linalg`. It supports reusable coefficient objects, derivatives, and
the documented extrapolation rules. Deterministic fixtures generated by R
4.6.0 cover both spline methods and averaged ties.

The scalar numerical interfaces use independent textbook implementations:
bracketed bisection with geometric interval expansion for `uniroot`,
safeguarded Brent minimization for `optimize`, and adaptive Simpson quadrature
with algebraic or tangent infinite-bound transformations for `integrate`.
Their result types expose convergence information without reproducing R's S3
objects, and deterministic R 4.6.0 fixtures check ordinary and extended roots,
extrema, finite integrals, both semi-infinite directions, and the whole real
line.

The generalized-linear-model engine reorganizes the runtime's initial
binomial and Poisson solvers around independently implemented, rank-aware IRLS.
Gaussian, Gamma, quasi-binomial, and quasi-Poisson families, eight standard
links, prior weights, offsets, dispersion, deviance, and step halving were
implemented from the documented model equations and checked against
deterministic R 4.6.0 output. No R source code was copied.

The additional exact-count, variance-ratio, Bartlett, and Friedman procedures
were implemented from their published distributional definitions. Exact
discrete p-values reuse `rfortran-core` probability masses and confidence
limits reuse its beta, chi-square, and F quantiles. Deterministic R 4.6.0
fixtures cover estimates, statistics, probabilities, confidence intervals,
grouped variances, blocked ranks, and ties.

Distance and hierarchical clustering are not copied from the original runtime.
They use the repository's `fastcluster` package, which is licensed under the
BSD 2-Clause License and preserves its upstream attribution to Daniel Muellner,
Google Inc., and later contributors.

The ACF and CCF adapters delegate their covariance calculations to the
MIT-licensed `rfortran-core` package. This keeps one canonical implementation
of biased lag covariance calculations in the repository.

The ARMA covariance solver and simulator were independently implemented from
the documented model equations and validated against deterministic R output;
no R source code was copied.

The direct-surface LOESS implementation expands and reorganizes the
MIT-licensed univariate local-polynomial helper in `R-to-Fortran`. Gaussian,
robust, and prior-weighted behavior is validated against deterministic R
output; no R LOESS source code is copied.

The smoothing-spline implementation independently constructs a cubic B-spline
design and roughness penalty from the documented penalized least-squares
problem. It preserves R's public `spar` mapping and legacy roughness quadrature
convention, default reduced-knot count schedule, and knot-selection behavior for
numerical parity. Predictor grouping independently reproduces R's public
centered-rounding tolerance behavior. GCV and ordinary CV use independently
implemented smoothing-matrix formulas, including observation-level leverage
adjustments after predictor grouping. No R smoothing-spline source code is copied.

The shared Fourier transform is an independent implementation of standard
mixed-radix Cooley-Tukey decomposition. It does not copy the package-local GPL
FFT implementations found elsewhere in the repository.

The nonlinear least-squares engine is an independent pure projected
Gauss-Newton implementation with active bounds, step halving, central finite
differences, rank diagnostics, and covariance from the final Jacobian. R `nls`
output is used only for deterministic behavioral fixtures. Profile intervals
are independently computed by fixing each parameter, refitting the remaining
parameters, and locating the profile-RSS threshold. No R nonlinear-model source
code is copied.

The separable nonlinear solver uses independently implemented variable
projection through shared pure linear-system routines. The self-start curve
helpers implement the mathematical formulas documented by R; R output supplies
deterministic value, gradient, and fit fixtures only.

No R source file is copied into this initial package. R and its `stats` source
remain subject to the licenses and attribution requirements of the R project.

Weighted least squares, sequential numerical-rank selection, and ANOVA sums of
squares are independent implementations of standard algorithms. Deterministic
fixtures from R `lm.wfit`, `lm.fit`, `aov`, and `anova.lm` validate coefficients,
fitted values, covariance, rank, sums of squares, F statistics, and p-values.

The multivariate linear-model and canonical-correlation implementations use
standard dense least squares, eigendecomposition, and singular-value
decomposition through the shared linear-algebra package. R fixtures validate
coefficient and SSCP matrices, canonical solutions, and the published MANOVA
test transformations without copying R implementation source.
