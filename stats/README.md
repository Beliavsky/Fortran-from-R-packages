# stats

This package is a staged modern free-form Fortran implementation of numerical
functionality from R's base `stats` package. The current release provides
selected regression, inference, multivariate, clustering, and smoothing
functions, extracted and modernized from the MIT-licensed
[`R-to-Fortran`](https://github.com/Beliavsky/R-to-Fortran) runtime.

The package uses the repository's shared `rfortran-core` and
`rfortran-linalg` packages rather than retaining the source runtime's duplicate
distribution and normal-equation implementations. It requires no separately
installed BLAS or LAPACK library.

## Using `stats` from another translation

For packages stored beside this directory, add the following local FPM
dependency:

```toml
[dependencies]
stats-fortran = { path = "../stats" }
```

Client code can then import only the required APIs, for example:

```fortran
use r_stats, only: glm_fit, median, quantile
```

New translations should depend on this package for implemented R `stats`
functionality instead of copying the corresponding algorithms locally.

## Implemented API

`quantile(x, probability, type=...)` and `iqr(x, type=...)` support all nine
Hyndman-Fan estimators through the pure shared `r_quantile` procedure.
Type 7 remains the default, and `quantile` accepts scalar or vector
probabilities. `na_rm=.true.` removes NaNs; otherwise NaNs propagate rather
than raising R's missing-data error. Empty samples yield NaN. Probability
names, ordered factors, user-specified fuzz, and R's small tolerance for
probabilities outside `[0,1]` are not implemented. Deterministic R fixtures
are generated by `reference/quantile_reference.R`.

Pure `box_test(x, lag, method, fitdf)` provides Box-Pierce (default) and
Ljung-Box autocorrelation tests for observations or fitted residuals. It reuses
the shared ACF calculation and returns a chi-square statistic, adjusted
degrees of freedom, and upper-tail probability. Inputs must be finite, with
`0 <= fitdf < lag < size(x)`; the default lag is one and `fitdf` is zero.
Constant series produce NaN statistics and probabilities. Run
`Rscript reference/diagnostics_reference.R` for the R reference cases.

Pure `oneway_test(values, groups, var_equal)` tests equality of group means.
The default is Welch's unequal-variance method; `var_equal=.true.` reuses
the pooled-variance ANOVA implementation. Arbitrary integer labels are
accepted, with at least two observations in each group. The result retains
the F statistic, real numerator and denominator degrees of freedom, p-value,
and status. Run `Rscript reference/oneway_reference.R` for the R fixtures.

Pure `fligner_test(x, group)` provides the median-centered Fligner-Killeen
test for equal group variances. It supports finite observations, ties, and
arbitrary integer group labels, with no allocation based on the largest
label. Formula input and automatic missing-value omission are not supported.
Run `Rscript reference/scale_tests_reference.R` for the R comparisons.

Pure `mcnemar_test(table, correct)` tests symmetry of integer or real square
contingency tables. The optional continuity correction defaults to true and
applies only to two-category tables. Results contain the statistic, degrees
of freedom, and p-value; zero opposite-cell totals produce NaNs as in R.
Run `Rscript reference/mcnemar_reference.R` to regenerate the reference cases.

Multiple-testing correction is available through pure `p_adjust(p, method, n)`.
Supported methods are `holm` (default), `hochberg`, `hommel`, `bonferroni`, `BH` (alias
`fdr`), `BY`, and `none`. Results retain input order and NaN positions. The
default hypothesis count excludes NaNs; an explicit `n` may include additional
unobserved hypotheses. Inputs must be probabilities in `[0,1]` or NaNs.
Hommel uses quadratic-time closed Simes testing, with unobserved hypotheses
assigned probabilities of one. Partial method-name matching is not supported.
Run `Rscript reference/multiple_testing_reference.R` for the R reference cases.

- `lm_fit` and compatibility name `lm_fit_general`, including prior weights
  and rank-deficient designs;
- `predict_lm` and compatibility name `lm_predict_general`;
- `lm_coef` and `lm_r_squared_general` convenience functions;
- `lm_confint` with arbitrary two-sided confidence levels;
- `lm_cooks_distance`; and
- `lm_aic` for constant-free Gaussian AIC-style comparison.
- `one_way_anova` for grouped one-way analysis of variance; and
- `anova_lm` for extra-sum-of-squares comparisons of nested linear models.

Linear-model results retain weights, numerical rank, and an alias mask.
Rank-deficient fits use the first independent design columns, preserve fitted
values, and mark confidence intervals for aliased coefficients as NaN. Run
`Rscript reference/linear_models_reference.R` to regenerate the weighted-fit,
rank-deficiency, one-way ANOVA, and nested-model fixtures.

The descriptive-statistics facade reuses `rfortran-core` and provides `median`,
all nine types of `quantile`, `sd`, vector or matrix `var`, vector or matrix `cov` and
`cor`, `cov2cor`, `iqr`, `mad`, and `weighted_mean`. These adapters are pure,
and the matrix overloads treat observations as rows and variables as columns.
Run `Rscript reference/descriptive_reference.R` to regenerate their R 4.6.0
fixtures.

The empirical-distribution slice adds compact `ecdf` objects with
`predict_ecdf`, plotting-free `histogram` results for explicit or equal-width
breaks, `bw_nrd0` and `bw_nrd` bandwidth selectors, and direct `density`
estimates with Gaussian, rectangular, triangular, or Epanechnikov kernels.
Run `Rscript reference/empirical_reference.R` to regenerate the exact ECDF,
histogram, bandwidth, and Gaussian-density comparisons.

The interpolation slice provides `approx`, reusable `approxfun` objects with
`predict_approxfun`, and increasing `isoreg` fits. Linear and constant
interpolation support averaged duplicate predictors, independent left and
right extrapolation rules, and R's constant-method mixing fraction. Isotonic
regression uses a pure weighted pool-adjacent-violators implementation. Run
`Rscript reference/interpolation_reference.R` to regenerate its fixtures.

Cubic interpolation adds `spline`, reusable `splinefun` objects, and
`predict_splinefun` evaluation for function values or derivatives through
order three. Both R's default FMM endpoint conditions and natural splines are
supported, including averaged duplicate predictors and the corresponding FMM
or linear-natural extrapolation. Run
`Rscript reference/spline_interpolation_reference.R` to regenerate its R
4.6.0 fixtures.

The scalar numerical-method slice provides `uniroot` for bracketed roots,
`optimize` for bounded minimization or maximization, and `integrate` for
adaptive finite or improper quadrature. All three accept explicitly pure
scalar callbacks and return typed convergence diagnostics. Root finding uses
safeguarded bisection with optional interval expansion, optimization uses
safeguarded Brent search, and integration uses adaptive Simpson refinement
with transformations for either or both infinite bounds. Run
`Rscript reference/numerical_reference.R` to regenerate the deterministic R
4.6.0 fixtures.

The generalized-linear-model slice provides:

- `glm_fit` as a common family/link interface;
- `glm_binomial_fit` for logit, probit, complementary-log-log, or cauchit models;
- `glm_poisson_fit` for log, identity, or square-root-link count models;
- `glm_gaussian_fit` with identity, log, or inverse links;
- `glm_gamma_fit` with inverse, log, or identity links;
- `glm_quasibinomial_fit` and `glm_quasipoisson_fit` with estimated dispersion;
- `glm_link_value`, `glm_inverse_link`, and `glm_mu_eta` link helpers;
- `glm_predict_response`; and
- `glm_pearson_resid`.

The common IRLS engine accepts an optional intercept, detects aliased design
columns, and retains rank, covariance, prior and working weights, dispersion,
and residual deviance. The GLM tests include deterministic coefficient,
fitted-value, standard-error, dispersion, deviance, link, and Pearson-residual
fixtures generated by R 4.6.0. Run
`Rscript reference/glm_reference.R` to regenerate the displayed reference
values independently of the Fortran implementation.

The multivariate-model slice provides `mlm_fit` for full-rank response
matrices, `manova_lm` for nested-model comparisons, and `cancor` for canonical
correlation analysis. MANOVA reports Pillai, Wilks, Hotelling-Lawley, and Roy
criteria with the same approximate F transformations used by R. Canonical
correlation results retain centers and coefficient matrices. Run
`Rscript reference/multivariate_reference.R` to regenerate these fixtures
together with the PCA, scaling, and Mahalanobis references.

The hypothesis-test slice provides generic `t_test` and `t_test_p_value`
interfaces for one-sample, Welch, equal-variance, and paired tests. Unlike the
earlier runtime implementation, it uses Student-t probabilities and quantiles
rather than a normal approximation. Its result type includes the statistic,
degrees of freedom, p-value, estimates, standard error, and 95 percent
confidence interval. Run `Rscript reference/t_test_reference.R` to regenerate
its four deterministic R 4.6.0 fixtures.

The classical-test slice also provides `chisq_test`, `prop_test`, and
`cor_test`. It covers goodness-of-fit and contingency-table chi-square tests,
one- and multiple-sample proportion tests, Pearson correlation tests, and
asymptotic Spearman tests. Run
`Rscript reference/classical_tests_reference.R` to regenerate its deterministic
R fixtures.

Additional pure tests provide exact two-sided `binom_test` and one-sample
`poisson_test` inference with exact confidence intervals, `var_test` for a
normal-population variance ratio, `bartlett_test` for grouped variances, and
`friedman_test` for complete blocked designs with tie correction. Run
`Rscript reference/additional_tests_reference.R` to regenerate their R 4.6.0
fixtures.

The rank and exact-test slice adds two-sided Fisher exact tests for 2-by-2
tables, asymptotic Wilcoxon rank-sum and paired signed-rank tests,
Kruskal-Wallis tests, and asymptotic Kolmogorov-Smirnov tests. Tie corrections
are included for Wilcoxon and Kruskal-Wallis statistics. The one-sample KS API
currently supports a normal reference distribution; the two-sample API accepts
two explicit vectors. Run `Rscript reference/rank_exact_tests_reference.R` to
regenerate the corresponding fixtures.

The multivariate slice adds `prcomp`, `scale`, and `mahalanobis`. PCA uses the
shared economy-size SVD and supports centering, scaling, and rank truncation.
Loading signs are normalized by making each component's largest absolute
loading positive, since singular-vector signs are mathematically arbitrary.
Scaling delegates to `rfortran-core`, while Mahalanobis distance delegates its
linear solve to `rfortran-linalg`. Run
`Rscript reference/multivariate_reference.R` to regenerate the R fixtures.

The clustering slice adds `dist`, deterministic Lloyd `kmeans`, `hclust`, and
`cutree`. Distance and hierarchical-clustering work delegates to the
BSD-2-Clause [`fastcluster`](../fastcluster) translation, avoiding another copy
of its linkage engine. K-means requires explicit initial centers, eliminating
RNG-dependent comparisons. Run `Rscript reference/clustering_reference.R` to
regenerate the deterministic R fixtures.

The smoothing slice adds `runmed`, `ksmooth`, `lowess`, `loess_fit`, and
`predict_loess`. The
implementations are pure, accept explicit deterministic inputs, and reproduce
fixed R 4.6.0 fixtures. `ksmooth` retains R's historical normal-kernel
bandwidth scaling and four-bandwidth tail truncation. The typed LOESS fit uses
univariate direct-surface tricube-weighted polynomials of degree zero through
two. It supports prior weights and Gaussian or Tukey-bisquare robust fitting,
and retains fitted values, residuals, and final robustness weights. Formula
processing, multivariate predictor surfaces, interpolation, and prediction
standard errors are not included. Run
`Rscript reference/smoothing_reference.R` to regenerate the fixtures.

The pure `smooth_spline` function fits a natural cubic smoothing
spline to at least four finite, distinct predictor values. Equal predictors
are aggregated using their normalized weights. At most one of `spar`, a target
`degrees_freedom`, or a positive `lambda` is supplied; when none is supplied,
bounded generalized cross-validation selects `spar` automatically. Setting
`ordinary_cv=.true.` instead selects it by leave-one-out cross-validation; the
same option reports ordinary CV for an explicitly parameterized fit. The fit
retains `gcv`, `cv`, and the criterion corresponding to the requested mode.
`predict_smooth_spline` evaluates the fitted curve or its first or second
derivative using `derivative=0`, `1`, or `2`. Natural linear extrapolation gives
constant first derivatives and zero second derivatives outside the data range.
Prior weights, fitted values, residuals, leverages, effective degrees of
freedom, and spline coefficients are retained.
For fewer than 50 distinct predictors every predictor is a knot; larger inputs
use R's reduced-knot count schedule. The caller can instead supply `n_knots` or
request `all_knots=.true.`. Linear algebra remains dense in the resulting basis
dimension. Predictors are grouped using R's default `1e-6*IQR(x)`
centered-rounding tolerance; callers may override it with the `tolerance`
argument. Observation-level leverage corrections are retained when ordinary
CV is requested with grouped predictors.

The time-series slice adds convolution and recursive `filter`, univariate
`acf`, `pacf`, and `ccf`. Filtering, covariance, and Durbin-Levinson kernels
delegate to pure shared implementations in `rfortran-core`; the adapters add
R lag and initial-state conventions plus typed result metadata. Both
correlation and biased covariance output are supported. Run
`Rscript reference/time_series_reference.R` to regenerate the deterministic
R fixtures.

Pure `decompose` support provides R-compatible classical additive and
multiplicative seasonal decomposition with the default centered moving
average or caller-supplied convolution weights. It returns the full trend,
seasonal, and random series plus the normalized seasonal figure. Holt-Winters
automatic initialization reuses this same public implementation.

The `stl` implementation adds seasonal-trend decomposition by LOESS with
configurable seasonal, trend, and low-pass windows, local degrees, smoothing
jumps, inner iterations, and robustness iterations. Periodic seasonal fitting
and Tukey-bisquare robustness weights are supported. Default and periodic
paths reproduce R to tight numerical tolerance; robust results can differ at
about the fourth decimal place because the independent implementation uses an
exact median rather than R's legacy partial-selection routine.

The same slice provides `arma_acf` for theoretical stationary ARMA
autocorrelations and `arima_sim` for deterministic nonseasonal ARIMA simulation.
The latter accepts retained and burn-in innovations explicitly instead of hiding
an RNG, supports ordinary integration through `difference_order`, and matches R
when the same `innov` and `start.innov` sequences are supplied.

ARIMA fitting is available through the pure `arima_css` function for explicit
multiplicative `(p,d,q)(P,D,Q)[s]` orders. It uses deterministic multistart
Nelder-Mead optimization and reproduces R's CSS conditioning, residual
alignment, innovation variance, and Gaussian log-likelihood conventions.
Both fitting functions accept optional `xreg`, `fixed_values`, and `fixed_mask`
arrays. Their coefficient order is ordinary AR, ordinary MA, seasonal AR,
seasonal MA, the mean when one is fitted, and user regressors in column order.
Regressors receive the same ordinary and seasonal differencing as the response.
A true mask element holds its corresponding value fixed; unlike R's API, no
missing-value sentinel is required. The fitted object retains this mask, and
an all-fixed model bypasses optimization. The
`coef_covariance` field contains the observed numerical-Hessian covariance in
the same full ordering. Rows and columns for fixed coefficients are zero;
`covariance_status` reports a singular or nonfinite Hessian without discarding
an otherwise usable fit.
`predict_arima` returns conditional point forecasts and reverses ordinary and
seasonal differencing. Fits with regressors require a conformable `new_xreg`
matrix for the forecast horizon. `predict_arima_interval` additionally returns
innovation-based standard errors and configurable normal prediction intervals.
Seasonal-MA forecasts can differ from R's `predict.Arima`, which initializes
residual state through its exact-likelihood state-space machinery even after a
CSS fit. These intervals condition on fitted regression coefficients and do not
add coefficient-estimation uncertainty. The time-series reference script
includes stationary, integrated, multiplicative seasonal, fixed-coefficient,
and regression fits, covariance matrices, and forecasts.

The pure `arima_ml` entry point adds profiled exact Gaussian likelihood after
ordinary and seasonal differencing. It obtains unit-innovation
autocovariances from `rfortran-core`, applies the Durbin-Levinson innovations
recursion, and starts deterministic likelihood optimization from the CSS fit.
Exact point forecasts use the corresponding finite-history covariance
predictor before ordinary and seasonal differences are inverted. Stationary,
integrated, seasonal, and combined-difference fits are checked against R 4.6.0.
Leading observations consumed by differencing have zero residuals rather than
R's negligible diffuse-initialization placeholders.

Exact-ML models may contain quiet NaNs marking unavailable response observations.
Stationary likelihoods use the covariance submatrix of the observed values, and
their residuals and forecasts use sequential Gaussian conditioning. Integrated
models use exact diffuse state-space initialization with separate diffuse and
finite covariance components. Ordinary and seasonal missing-data fixtures match
R's likelihoods, variances, forecasts, and interval standard errors. CSS models
still require complete data: an internal gap can propagate through the
conditional MA recursion and produce an unstable fit even in R.

The Holt-Winters slice provides pure additive and multiplicative seasonal
filtering through `holt_winters` and point forecasts through
`predict_holt_winters`. `holt_winters_auto` reproduces R's classical seasonal
decomposition and trend-regression initialization, while
`holt_winters_optimize` uses deterministic multistart bounded Nelder-Mead to
estimate all three smoothing parameters. The lower-level entry point accepts
explicit initial states. The result retains one-step fitted values, residuals,
state histories, initial and final states, SSE, and optimization metadata.
`holt_winters_reduced` covers nonseasonal Holt linear-trend and simple
exponential-smoothing models; the lower-level filter also supports seasonal
models without trend. `predict_holt_winters_interval` returns point forecasts,
standard errors, and normal prediction limits using R's forecast-variance
recurrences and residual sample variance. Multiplicative intervals currently
require a trend component; R itself produces undefined bounds at some horizons
for the multiplicative no-trend combination.

The autoregression slice provides Yule-Walker, Burg, and unconstrained OLS
and exact Gaussian ML paths through `ar`, with focused `ar_yw`, `ar_burg`,
`ar_ols`, and `ar_mle` entry points.
Each method supports fixed orders or relative-AIC order selection and returns
coefficients, innovation variance, the fitted mean, residuals, and candidate
AIC values. OLS also reports its centered-series intercept, while Burg offers
both R variance estimators. ML uses stationary reflection-coefficient
parameterization and a pure bounded Nelder-Mead optimizer. Its default
`mle_delta=0` retains the exact likelihood; a positive value enables a faster
steady-state approximation. `spec_ar` evaluates any supported fitted path
from zero through the Nyquist frequency.

The spectral slice adds raw and modified-Daniell-smoothed univariate and
multivariate `spec_pgram` overloads and their `spectrum` aliases. It supports
R-compatible odd `spans`, autospectra, complex cross-spectra, squared
coherence, phase,
detrending, demeaning, split-cosine tapering, fractional zero padding,
sampling frequencies, fast transform-length padding, spectral scaling,
degrees of freedom, and bandwidth metadata. Fourier, kernel construction, and
circular smoothing use pure implementations in `rfortran-core`. The reference
script tests raw, smoothed, multivariate, and default detrended and tapered
paths.

The current fitting API accepts a real response vector and a dense real
predictor matrix. The predictor matrix does not contain an intercept column;
an intercept is included by default and can be disabled explicitly.

```fortran
use r_stats, only: dp, lm_fit, lm_fit_t, predict_lm

real(dp) :: x(5, 1), y(5), new_x(2, 1)
type(lm_fit_t) :: fit

x(:, 1) = [0.0_dp, 1.0_dp, 2.0_dp, 3.0_dp, 4.0_dp]
y = 1.5_dp + 2.0_dp*x(:, 1)
fit = lm_fit(y, x)

new_x(:, 1) = [5.0_dp, 6.0_dp]
print *, predict_lm(fit, new_x)
```

The pure `nls_fit` function provides formula-free nonlinear least squares.
Callers supply a pure model callback receiving the predictor matrix and current
parameter vector. An optional pure analytic-Jacobian callback improves accuracy
and avoids finite differences; otherwise a central numerical Jacobian is used.
The Gauss-Newton solver uses step halving and optional `lower` and `upper`
parameter bounds. At active bounds it solves only for the remaining free
parameters. The pure `nls_confint_profile` function fixes each parameter in
turn, refits the others, and locates profile-RSS confidence bounds using the
appropriate Student-t threshold. `nls_fit` returns coefficients, fitted
values, residuals, RSS, residual standard error, parameter covariance,
standard errors, Jacobian rank, convergence status, and iteration count.
Rank-deficient Jacobians receive an explicit singular status. Formula
processing, partially linear models, and the complete R `port` algorithm are
not included.
Run `Rscript reference/nls_reference.R` to regenerate the exponential-growth,
profile-interval, partially linear, Michaelis-Menten, and self-start curve
fixtures.

For separable models, `nls_fit_plinear` profiles the linear coefficients at
every nonlinear iteration, corresponding to R's `nls(...,
algorithm="plinear")`. The returned coefficient vector contains nonlinear
parameters first and profiled linear coefficients second. Pure elemental curve
functions and matching model/Jacobian callbacks are provided for `SSasymp`,
`SSgompertz`, `SSlogis`, `SSmicmen`, and `SSweibull`. They reproduce the R
curve and gradient formulas but deliberately omit R's formula-driven automatic
starting-value machinery.

## Build and test

Place this directory at the root of `Fortran-from-R-packages`, beside its
shared dependencies, and run:

```text
fpm build
fpm test
fpm run --example linear_model
```

Shared test assertions live in the development-only `test-support` package.
All test programs use these common helpers. They are not part of the public
`r_stats` facade or a production dependency.

## Scope

This is not yet a complete replacement for R's `stats` package. Formula and
model-frame processing, factors and contrasts, weighted fits,
rank-deficient model reporting, S3 methods, printing, plotting, and most other
model families remain outside the initial slices.
Multivariate ACF, alternative PACF estimators, circular filtering, and seasonal
simulation remain future slices. See
[`API_COVERAGE.md`](API_COVERAGE.md) and
[`TRANSLATION_INVENTORY.md`](TRANSLATION_INVENTORY.md).
