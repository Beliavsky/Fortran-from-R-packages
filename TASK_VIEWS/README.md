# Task views

These task views organize the translated packages by statistical or numerical
task. They complement the alphabetical package table, the
[category and keyword index](../PROJECT_INDEX.md), and the
[NIST GAMS index](../GAMS_INDEX.md).

Each view is an independent, filtered adaptation of the corresponding CRAN
Task View. It includes only packages translated in this repository and
describes only the high-level computational scope documented by the Fortran
translation. Plotting, graphical interfaces, R classes, data-frame operations,
and other untranslated facilities are omitted. Internal implementation details,
including migration into shared Fortran modules, do not affect membership or
the descriptions.

The source CRAN Task View, its maintainers, and its version date are credited
on every adapted view. These pages are unofficial and are not endorsed by CRAN,
the R Foundation, the original task-view maintainers, or the R package authors.

## Available views

- [Time Series Analysis](TimeSeries.md)
- [Empirical Finance](Finance.md)
- [Missing Data](MissingData.md)
- [Optimization and Mathematical Programming](Optimization.md)
- [Numerical Mathematics](NumericalMathematics.md)
- [Probability Distributions](Distributions.md)

Additional views will be added as their translated-package coverage is
reviewed.

The Finance, Missing Data, Optimization, Numerical Mathematics, and
Probability Distributions views are generated by
[`generate_task_views.py`](../generate_task_views.py). The generator obtains
package membership and topic organization from the current source task view,
intersects package names with top-level FPM projects, and uses the curated
high-level descriptions in the main README. The Time Series view is maintained
separately so it can retain more detailed descriptions of translated scope. Run

```text
python generate_task_views.py
```

to refresh them, or use `--check` to test whether they are current without
writing files.
