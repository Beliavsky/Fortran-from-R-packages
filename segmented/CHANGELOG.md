# Changelog

## 2.2.1-fortran.1

- Initial modern Fortran/FPM computational translation of segmented 2.2-1.
- Added continuous and step change-point regression for Gaussian, binomial, and
  Poisson models.
- Integrated the previous `nlme-fortran` implementation for segmented mixed
  models.
- Added model matrices, prediction, slopes/intercepts, AAPC, confidence
  intervals, score/Davies-style tests, power, and BIC breakpoint selection.
- Added strict tests, examples, documentation, and cross-platform GNU Fortran
  validation scripts.
