# Validation

## Environment

The translated source was validated on 2026-09-09 with:

```text
GNU Fortran (Debian 14.2.0-19) 14.2.0
```

The validation container does not provide the Fortran Package Manager (`fpm`) and cannot resolve external hosts to install it. Literal attempts to run the required FPM commands therefore return exit status 127; the captured attempts are in `provenance/FPM_ATTEMPTS.txt`. This document does not claim that a literal Windows/FPM build was executed in this container.

The FPM manifest was parsed as TOML and the maintained source graph was compiled directly with GNU Fortran. Sibling validation API stand-ins for `rfortran-core`, `rfortran-linalg`, and `waveslim` were kept outside the release tree and compiled before the package sources. The package itself retains only the required sibling FPM path dependencies and contains no copied dependency source. The stand-ins validate the translated package's explicit interfaces and package-side numerical logic; they are not substitutes for a final FPM build against the actual sibling repositories. In particular, the 3-D adapter wiring is checked against the sibling API shape rather than independently reimplementing the sibling 3-D transform in the validation harness.

## Deterministic numerical coverage

The tests exercise, among other translated paths:

- Haar and non-Haar 1-D transform/reconstruction, packet transforms, and upstream-style recursive stationary `wst`/average-basis reconstruction. A Haar test also checks expected stationary packet coefficients directly, not only reconstruction.
- Minimum-entropy basis selection for ordinary and stationary packets (`AutoBasis`, `MaNoVe.wp`, `MaNoVe.wst`), all eight 8-point Haar `numtonv` stationary paths, `InvBasis.wp`, and `InvBasis.wst` reconstruction.
- R-style packet addressing, `getpacket.wpst`, stationary packet extraction, packet rotations, `wpst2m`, `wpst2discr`, and `wpstREGR`, plus construction of typed `makewpstRO` regression models.
- Pooled-covariance LDA (`BMdiscr`), packet-discrimination model construction (`makewpstDO`), and packet classification (`wpstCLASS`), including deterministic class means, priors, inverse covariance, and a two-regime classification example.
- 2-D decimated/stationary package-side transforms and the 3-D sibling-adapter interface/reconstruction wiring.
- Manual/universal/SURE thresholding, componentwise and joint `threshold.mwd`, plus the Ogden-Parzen rule-1/rule-2 sequential threshold procedures.
- SURE/newsure, norms, robust statistics, claw density/CDF, Fourier packing/inversion, decimated wavelet cross-validation, scalar stationary `wstCV`, and level-specific `wstCVl`/`wvcvlrss` objectives.
- High-resolution density projection (`Chires5`, `Chires6`, and `denproj`), including exact Haar coefficients/covariance bands and Daubechies-2 coefficients independently generated by upstream wavethresh 4.7.3; sampled-basis `CWavDE`, zero-boundary `denwd`, and dense covariance `dencvwd` are checked against upstream grid, bounds, coefficient, and variance values.
- Adaptive interval `wd.int` coefficients and filter history with and without boundary preconditioning, checked against upstream wavethresh 4.7.3, plus reconstruction checks for every supported filter order.
- Stationary 2-D base-four packet addressing for all S/H/V/D bands, packet replacement round trips, and invalid-address rejection.
- Irregular-grid variance propagation, including the unit-variance identity-grid invariant, typed `accessc` shape/range checks, and variance-adjusted manual hard/soft thresholding.
- Periodic Lina-Mayrand 3.1 complex transform/reconstruction, exact complex coefficients, robust noise covariance, and multiwavelet-style `cthresh` output against upstream wavethresh, plus deterministic empirical-Bayes parameter bounds and finite posterior-mean reconstruction.
- `BAYES.THR` on deterministic periodic data, including locked posterior-shrinkage reference blocks and the zero-variance fixed point.
- `first.last`, zero-boundary `first.last.dh`, multiple-wavelet `mfirst.last`, grid interpolation, scaling-function refinement, and wavelet moments.
- Upstream Yates filter coefficients and Geronimo/Donovan3 multiple-wavelet filter tables.
- All upstream Geronimo/Donovan3 pre/postfilter branches, periodic `mwd`/`mwr` round trips, and typed multiple-wavelet coefficient access/mutation.
- Deterministic signal generators, seeded simulation paths including `LSWsim` and `checkmyews`, dense 2-D compress/uncompress compatibility, packet mutation, and one-level `conbar` synthesis.
- Autocorrelation wavelets (`PsiJ`/`PsiJmat`), their inner-product matrix (`ipndacw`), raw stationary local periodograms, and the unsmoothed stationary `ewspec` correction, including documented Haar references and a non-Haar LA10 case.

These tests establish consistency of the translated numerical paths. They do not imply bit-for-bit R RNG equivalence, identical `MASS::lda` rank/SVD behavior, or identical R/NAG optimizer trajectories for `wstCVl` and `find.parameters`.

## Release audit

`scripts/audit.py` checks:

- ASCII-only maintained Fortran source and maximum 132-column free-form lines.
- every dummy argument has explicit `INTENT` or `VALUE`, is declared alone, and has a trailing meaningful `!!` FORD comment.
- no forbidden `double precision`, `real*8`, `d0`/`D0`, or `kind(0.0d0)` forms.
- no semicolon-separated executable statements.
- no self-comparison NaN tests.
- no duplicate maintained Fortran source files.
- no copied dependency source under the package source tree.
- no locally generated objects, modules, executables, libraries, caches, or nested ZIP files in the release tree.
- consistency of the `fpm.toml` translation metadata, README coverage table, and untranslated list.

The current Windows/FPM validation adds deterministic density-projection, adaptive interval-wavelet, and complex-threshold checks against the installed upstream wavethresh R/C implementation, plus typed stationary 2-D packet and irregular-grid variance tests. A full `fpm test` passes, including the upstream Haar `wavepackst` coefficient rows and dependent `InvBasis.wst` reconstruction paths. Translation metadata records 161 of 162 mapped computational exports (99.4%), with the sole error-only untranslated export listed explicitly.

The retained `upstream/` source files were compared recursively against the supplied upstream archive. Every retained file matches byte-for-byte. The archive's generated `build/partial.rdb` is the sole intentional omission; its original path and SHA-256 are recorded in `provenance/OMITTED_UPSTREAM_BUILD_ARTIFACTS.txt`.
