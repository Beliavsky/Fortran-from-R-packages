# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `goftest` 1.2-3.
- Ported Anderson-Darling fast, finite-sample, and high-accuracy asymptotic CDFs.
- Added Anderson-Darling quantiles and test statistics.
- Ported Csorgo-Faraway Cramer-von Mises null distribution and quantiles.
- Added an internal fractional modified-Bessel K evaluator.
- Added simple-null and Braun-adjusted goodness-of-fit tests.
- Added scalar and vector probability/quantile interfaces.
- Added CDF callback API and `recognise_cdf` helper.
- Added strict numerical, inversion, monotonicity, callback, and special-function tests.
