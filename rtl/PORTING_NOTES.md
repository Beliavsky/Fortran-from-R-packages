# Porting notes

## Array and object model

R data frames and lists are replaced by typed Fortran results with allocatable arrays. Dates are integer serial days generated by `ymd_to_serial`; business-day functions take caller-supplied holiday serials.

## Upstream-compatible behavior and corrections

### Multivariate starting values

The R documentation says that `s0` is a caller-supplied starting vector. The implementation instead uses the final historical observation whenever `s0` is non-null. The Fortran default follows the documented behavior. `use_last_start=.true.` reproduces the implementation behavior.

### Covariance safeguard

The upstream covariance is built from sample standard deviations and a Kendall correlation matrix. Such a matrix can be numerically indefinite. The port symmetrizes it and floors negative eigenvalues before Cholesky simulation. `covariance_adjusted` reports whether this was necessary.

### OU jump sizes

Upstream calls `rlnorm(n=1, ...)` and recycles that one draw over every simulated jump. The port draws an independent lognormal size for each jump by default. `legacy_recycled_jump=.true.` reproduces the recycled-size behavior.

### NPV terminal cash flow

Upstream replaces the final periodic cash flow with terminal value. This remains the default. Set `terminal_replaces_cash_flow=.false.` to add terminal value to the final periodic cash flow.

### Interest-rate swaps

The upstream documentation lists a six-month reset frequency, but no branch creates that schedule. The port supports any positive integer number of reset months, including six. It uses actual calendar dates and ACT/360 or ACT/365 accruals.

R's default `spline` is not available as an intrinsic Fortran operation. The port uses a natural cubic spline and clamps curve requests to the supplied endpoint range.

### Barrier spread monitoring

The upstream routine validates `monitoring` as `continuous` or `terminal`, but the argument is absent from the calculation. The port retains the argument and returns `monitoring_used=.false.`. Prices are not rounded unless `upstream_round=.true.` is supplied.

### Refinery LP

The native simplex routine solves the form

```text
maximize c'x
subject to A x <= b
           x >= 0
           b >= 0
```

This is the exact form needed by `refineryLP`. It is not a general mixed-integer or equality-constrained solver.

### Performance statistics

The R routine delegates several calculations to PerformanceAnalytics and tidyquant. The dependency-free Fortran definitions are:

- cumulative return: product of one plus periodic returns minus one;
- annualized return: geometrically annualized cumulative wealth;
- annualized standard deviation: sample standard deviation times square root of periods per year;
- Sharpe ratio: annualized return minus annual risk-free rate, divided by annualized standard deviation;
- Omega ratio: sum of gains over the periodic threshold divided by sum of losses below it;
- maximum drawdown: minimum cumulative-wealth drawdown from its running peak;
- drawdown length: maximum consecutive observations below the running peak.

These are mathematically standard equivalents, but may not be bit-for-bit identical to every version of the R dependencies.

### Trading strategies

`tradeStrategyDY` is identical to `tradeStrategySMA` in the supplied package and does not use dividend yield. The port provides both names over one implementation.

### Roll adjustment

The numerical action in the upstream return-data branch is removal of the observation immediately after an expiry date. `roll_adjust_mask` returns a logical keep mask so callers can apply it to any associated arrays.

## Random numbers

The project uses the compiler's `random_number` generator with Box-Muller normal generation and optional deterministic integer seeds. Identical seeds are reproducible within a compiler/runtime, but are not expected to match R's random stream or another compiler exactly.
