# Origin and licensing

This project translates computational routines from:

- Package: `fExtremes`
- Version: `4032.84`
- Title: Rmetrics - Modelling Extreme Events in Finance
- Authors listed by the package: Diethelm Wuertz, Tobias Setz, Yohan Chalabi,
  and Paul J. Northrop
- Source license declaration: `GPL (>= 2)`

The translation therefore uses `SPDX-License-Identifier: GPL-2.0-or-later` in
every Fortran source file. `LICENSE` contains GNU GPL version 2; the
"or later" option follows the original package declaration.

The original source archive is not redistributed inside the release ZIP.
`API_MAP.md` records the numerical mapping and exclusions.
