# Changelog

## 0.1.0

* Initial modern Fortran/FPM translation of CCd 1.1.
* Ported all seven computational exports.
* Added standalone Nelder-Mead and golden-section optimization.
* Removed Rfast/stats runtime dependencies.
* Added regression, probability, optimizer, and property tests.
* Documented the upstream nonzero-location PMF/CDF consistency limitation.
