# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation.
- Added NNLS, partial NNLS, LDP, LSI, LSEI, QP, partial-nonnegative QP, HFTI
  result interface, `indx`, and matrix maxima.
- Added standalone eigensolver, pseudoinverse/null-space and active-set
  constrained least-squares support.
- Added strict regression tests and examples.
