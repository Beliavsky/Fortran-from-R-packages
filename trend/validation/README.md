# Validation

Actual reference runtime: R 4.5.0, trend 1.1.8 built from CRAN-mirror revision
`ee55a676a23b2d080d953fe82e627216562f45bf`, extraDistr 1.10.0. Session details
are preserved in `R-session.txt`. These are source/reference data, not caches.

`test/r_reference.f90` is generated by `generate_reference.R` from actual public
R function results. From the package root, with the pinned R package installed:

```text
Rscript validation/generate_reference.R
fpm test
```

The stored fixture makes ordinary `fpm test` independent of R and network access.
No reimplementation of the R formulas generated the reference values. The
reference script calls every one of the 19 exported computational functions.

Current deterministic suite: **469 assertions**, covering:

- All 19 functions; even/odd ITAM, tied/untied scores, all normal tails,
  confidence bounds, normal/beta Bartels regimes, seasonal and multisite covariance
- Exact and tie-corrected asymptotic Wilcoxon Lanzante significance
- All three upstream Monte Carlo kernels with the identical R-generated normal
  sample matrix; exact agreement of exceedance counts and p-values
- Separate 50000-draw comparisons with the local generator, allowing 0.015
  relative-plus-absolute tolerance, a conservative combined Monte Carlo bound
- Independent monotone-score/variance and exact-line slope oracles, reversal and
  affine invariances, offset 1e8 and magnitude 1e200 stability checks (including ITAM and partial correlations)
- Missing/nonfinite data policies, constant/short inputs, invalid options,
  incomplete seasons, repeated maxima, constant null samples, and RNG repeatability

Most numerical comparisons use 2e-10 relative-plus-absolute tolerance. Degenerate
and infinite cases are checked explicitly rather than hidden by that tolerance.

Upstream WW raw moments suffer cancellation for large offsets. The translation
centers/scales before computing moments, so the corrected oracle in that regime
is `ww.test(x-x[1])`, consistent with location invariance. Change-point calculations
also center/scale for stability. Their centered/scaled oracle preserves exactly
the original mathematical formulas and observed/simulated SD conventions.

An independent reviewer additionally compared 96 data cases across 37 numerical
fields (3552 scalar comparisons), including tied, untied, scaled 1e12 and shifted
1e8 cases. Ordinary cases match raw R; shifted cases match the centered stable
oracle. This external probe is distinct from the self-contained delivered suite.

## Build profiles

The package was tested with Linux gfortran 14.2.0 and FPM 0.13.0. A native Windows
compiler run has not been performed; the dependency closure needs no external
BLAS/LAPACK installation or OS-specific runtime calls.

```text
fpm build
fpm test
fpm run --example trend_demo
fpm build --profile debug --flag "-Wall -Wextra -fcheck=all -fbacktrace -ffpe-trap=invalid,zero,overflow"
fpm test --profile debug --flag "-Wall -Wextra -fcheck=all -fbacktrace -ffpe-trap=invalid,zero,overflow"
fpm run --example trend_demo --profile debug --flag "-Wall -Wextra -fcheck=all -fbacktrace -ffpe-trap=invalid,zero,overflow"
fpm build --profile release
fpm test --profile release
fpm run --example trend_demo --profile release
```

For validation after source changes, first use `fpm clean --all` to avoid stale
profile/test-link artifacts. Do not use fast-math/finite-math assumptions. The
release validation uses ordinary `-O3`, not `-Ofast`.
