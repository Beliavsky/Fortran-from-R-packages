# Changelog

## 0.1.0

- Initial combined modern Fortran translation of the computational surface in
  `fNonlinear`.
- Added six chaotic map/system simulators and explicit-time RK4 integration.
- Added embedding, mutual information, recurrence, separation, correlation
  integral, false-neighbor, and Lyapunov calculations.
- Added direct, box-index, and automatic neighbor searches.
- Added BDS, White neural-network, Terasvirta neural-network, and runs tests.
- Added plain-array test result types and a generic test dispatcher.
- Added strict debug/release build scripts, four numerical test suites, a demo,
  a CSV analyzer, an example, sample data, provenance, and license auditing.
