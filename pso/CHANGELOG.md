# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `pso` 1.0.4 computational code.
- Added SPSO2007 and SPSO2011.
- Added synchronous/vectorized and asynchronous update paths.
- Added hybrid bounded limited-memory BFGS refinement.
- Added benchmark/test-result computational support.
- Added strict GNU Fortran validation scripts and examples.
