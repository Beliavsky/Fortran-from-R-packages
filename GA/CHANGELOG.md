# Changelog

## 0.1.0 - 2026-08-10

Initial modern Fortran/FPM translation of the computational algorithms in
GA 3.2.5.

### Added

- binary, real-valued, and permutation generational GA engines;
- all native GA selection/crossover/mutation operator families;
- Differential Evolution;
- coarse-grained ring-migration island GAs for all three representations;
- suggestions, elitism, run/max-fitness stopping, fitness summaries, history,
  and evaluation counts;
- adaptive mutation probability;
- binary/Gray conversion and bound repair/reflection utilities;
- FPM manifest, examples, regression tests, and preserved GPL provenance.
