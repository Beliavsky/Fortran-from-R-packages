# Upstream provenance

This project is a Fortran translation of the computational code in:

`poibin` 1.6, Yili Hong, CRAN release dated 2024-08-23.

Upstream package description states:

- implementation of exact and approximation methods for the Poisson-binomial
  CDF described by Hong (2013);
- FFT C code by the R Core Team, implementing the algorithm of Singleton
  (1969);
- license GPL-2.

References:

Yili Hong (2013). On computing the distribution function for the Poisson
binomial distribution. Computational Statistics & Data Analysis 59, 41-51.

R Core Team (2019). R: A Language and Environment for Statistical Computing.

R. C. Singleton (1969). An algorithm for computing the mixed radix fast
Fourier transform. IEEE Transactions on Audio and Electroacoustics 17, 93-103.
