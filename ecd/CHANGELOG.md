# Changelog

## 0.9.2.4-fortran.1 - 2026-07-29

- Added modern Fortran/FPM implementation of the package's numerical core.
- Added ECD, ECLD, SGED, stable-count, Lihn-Laplace, SLD/QSLD, and LAMP models.
- Added density, CDF, quantile, random generation, moments, transforms, fitting,
  option pricing, and numerical utilities.
- Added closed-form quartic MGF, IMGF, OGF, and option-smile operations.
- Added explicit portable RNG state and self-contained special functions.
- Added compatibility aliases for major original exports.
- Added application, examples, permanent tests, documentation, and GNU Fortran
  build scripts.
- Preserved the Artistic-2.0 license and complete original package tree.
