# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of coneproj 1.23 computational code.
- Added standalone coneA, coneB, qprog, shape-edge, constrained-regression, shape-regression, inference, QR/rank, and irreducibility routines.
- Removed R/Rcpp/Armadillo runtime requirements.
- Added strict GNU Fortran regression suite and examples.
