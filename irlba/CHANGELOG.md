# Changelog

## v0.1.0

- Initial modern Fortran/FPM computational translation of `irlba` 2.3.7.
- Added real dense and CSC sparse IRLB with restart, center, scale, and shift.
- Added PCA, partial eigen, sparse SVD, randomized SVD, complex compatibility
  SVD, and matrix-free operator interface.
- Added strict regression and randomized differential validation.
