# Licensing and provenance

This project is a modern Fortran translation of the computational code in the
R package **ABCoptim 0.15.0**.

The upstream package declares `License: MIT + file LICENSE`. Its `LICENSE`
file identifies 2017 and George G. Vega Yon as the copyright holder. The
translation therefore uses the MIT license and retains the upstream package
under `original/ABCoptim-master/` for provenance.

The original package states that its implementation was developed from the
basic Artificial Bee Colony implementation distributed at the ABC algorithm's
official website and cites D. Karaboga's 2005 technical report.

No claim is made that the Fortran translation is an official release by the
upstream ABCoptim authors.
