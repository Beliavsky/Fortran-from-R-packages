# Changelog

## 0.6.1-fortran.1 - 2026-08-01

- Initial modern Fortran/FPM translation of the computational code in `ldhmm` 0.6.1
- Added self-contained exponential-power distribution routines
- Added log-space HMM likelihood, decoding, forecasting, and simulation
- Added BFGS and Nelder-Mead maximum-likelihood fitting
- Added tests, examples, API documentation, and retained upstream sources
- Excluded plotting, network access, and R-specific class/data infrastructure
