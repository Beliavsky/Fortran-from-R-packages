# Upstream provenance

This project is a modern Fortran translation of the computational code in the
R package `bayesm` version 3.1-7.

Upstream package metadata:

- Package: bayesm
- Version: 3.1-7
- Author/maintainer: Peter E. Rossi
- Contributors: Robert McCulloch, Wayne Taylor, Dan Yavorsky
- License: GPL (>= 2)
- CRAN package description date: 2025-11-09

The original `DESCRIPTION`, `NAMESPACE`, R sources, and Rcpp/Armadillo C++
sources are retained under `upstream/` for license/provenance and algorithmic
comparison. They are not part of the FPM build and are not linked at runtime.
