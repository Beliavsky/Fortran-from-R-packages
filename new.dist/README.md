# new.dist-fortran

Modern Fortran/FPM translation of the computational code in R package `new.dist` 0.1.2.

All 18 upstream distribution families and all 72 exported d/p/q/r routines are represented.
The supplied VGAM, expint, and pracma translations are vendored as FPM dependencies.

See `API_MAP.md` and `PORTING_NOTES.md`.
