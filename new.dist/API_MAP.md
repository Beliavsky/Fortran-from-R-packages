# API map

All 72 NAMESPACE exports are translated. R names map directly to case-insensitive Fortran names:

`dEPd/pEPd/qEPd/rEPd`, `dLd/pLd/qLd/rLd`, `dRA/pRA/qRA/rRA`,
`dbwd/pbwd/qbwd/rbwd`, `ddLd1/pdLd1/qdLd1/rdLd1`,
`ddLd2/pdLd2/qdLd2/rdLd2`, `dgld/pgld/qgld/rgld`,
`dkd/pkd/qkd/rkd`, `dmd/pmd/qmd/rmd`, `domd/pomd/qomd/romd`,
`dpldd/ppldd/qpldd/rpldd`, `dsgrd/psgrd/qsgrd/rsgrd`,
`dsod/psod/qsod/rsod`, `dtpmd/ptpmd/qtpmd/rtpmd`,
`dtprd/ptprd/qtprd/rtprd`, `dugd/pugd/qugd/rugd`,
`duigd/puigd/quigd/ruigd`, and `dwgd/pwgd/qwgd/rwgd`.

Density/CDF/quantile routines are scalar. Random generators are subroutines whose first argument is the output array.
