# Changelog

## 0.1.0 - Fortran translation

- Translated all three exported Fingraph estimators.
- Translated the Student-t weight and augmented-Lagrangian helpers.
- Adapted required graph operators and dense numerical routines from
  spectralGraphTopology-fortran.
- Adapted portable Gaussian and Student-t simulation support from
  fitHeavyTail-fortran.
- Added FPM packaging, tests, examples, API documentation, and porting notes.
- Preserved and documented the original repository's GPL/MIT license mismatch.
- Omitted plotting, progress bars, R packaging, data downloads, and binary data.
