# Original material not copied into this source distribution

The following items from the R repository are noncomputational or large binary
artifacts and were intentionally omitted:

- `.github/`, `.Rbuildignore`, `.gitignore`, `.roxygenize.R`, and `Makefile`
- generated `README.html`
- RDS market data
- CSV symbol/sector tables
- Jupyter notebooks used for data collection and plotting
- generated graph images
- the RFinance presentation PDF and vignette wrapper
- R testthat packaging files

All three R computational source files, package metadata, generated manual pages,
and the original README are retained.
