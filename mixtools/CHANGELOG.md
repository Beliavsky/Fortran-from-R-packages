# Changelog

## 2.0.0-fortran.1

- Initial modern Fortran/FPM translation of the `mixtools` 2.0.0 numerical
  surface.
- Added typed result and control structures.
- Added parametric, regression, semiparametric, reliability, simulation,
  bootstrap, model-selection, MCMC, and numerical utility modules.
- Added four tests, three examples, one demo, and GNU Fortran validation
  scripts.
