# Upstream provenance

This project is a Fortran translation of the computational code from the R
package `contfrac` 1.1-12.

Upstream metadata from `DESCRIPTION`:

```text
Package: contfrac
Title: Continued Fractions
Version: 1.1-12
Author: Robin K. S. Hankin
License: GPL-2
URL: https://github.com/RobinHankin/contfrac.git
```

The `upstream/` directory contains copies of the relevant original files from
the user-supplied source archive:

- `DESCRIPTION`
- `NAMESPACE`
- `contfrac.R`
- `contfrac.c`

They are retained to make the algorithmic correspondence and license provenance
straightforward to inspect.
