# Changelog

## 0.1.0

- Initial modern Fortran translation of treasuryTR 0.1.6.
- Added elemental duration, convexity, and one-period return routines.
- Added vector and matrix total-return interfaces.
- Added LOCF and percentage preprocessing.
- Added stable zero-yield mode and explicit status diagnostics.
- Added FPM and Make builds, example, tests, documentation, and provenance.
