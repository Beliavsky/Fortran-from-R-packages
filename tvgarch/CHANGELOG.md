# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of `tvgarch` 2.4.3.
- Added TV transitions, univariate TV-GARCH-X, DCC/CCC multivariate models,
  spillover fitting, forecasts, robust inference, and transition-order tests.
- Vendored the supplied GPL-compatible `garchx` Fortran translation.
