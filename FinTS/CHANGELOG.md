# Changelog

## 0.4.9 - Fortran translation

- Translated the computational core of all relevant FinTS exports.
- Added univariate ACF, autocovariance, PACF, and multivariate cross-ACF.
- Added Ljung-Box, Box-Pierce, rank Box, and ARCH LM tests.
- Added asymptotic PCA with a self-contained symmetric eigensolver.
- Added ARMA roots, stationarity testing, theoretical ACF/PACF, damping, and periodicity.
- Added nonseasonal and seasonal conditional-Gaussian ARIMA fitting with regressors.
- Added financial return/interest transforms and numeric month conversion.
- Added FPM metadata, tests, demo, examples, GNU Fortran scripts, API notes, and coverage documentation.
- Preserved GPL-2.0-or-later licensing and original source provenance.
