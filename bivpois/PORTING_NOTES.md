# Porting notes

## Distribution representation

For nonnegative component rates `lambda = (lambda1, lambda2, lambda3)`, the model is generated by

```text
X = Z1 + Z3
Y = Z2 + Z3
```

with independent Poisson variables `Zj ~ Poisson(lambdaj)`. The PMF is evaluated directly from this convolution in log space. This avoids explicit factorials and potentially unstable powers used in the R implementation.

## Maximum likelihood

As in upstream `bp.mle`/`bp.mle2`, the fitted marginal means are fixed at the sample means:

```text
lambda1 = mean(X) - lambda3
lambda2 = mean(Y) - lambda3
```

so optimization is only over `lambda3`. A golden-section maximizer is used because the objective is one-dimensional and bounded. This replaces R's `optimize`/L-BFGS-B machinery without changing the statistical parameterization.

The full `bp_mle` computes the observed profile curvature numerically and translates the upstream Kawamura asymptotic-variance calculation. The latter uses the same finite support extension `max(observed count) + 20`, but probabilities are evaluated robustly with the log-PMF.

## Probability tails

For the R calls used by this package:

- `pnorm(-z)` is evaluated with `0.5*erfc(z/sqrt(2))`.
- the upper tail of chi-square with one degree of freedom is evaluated with `erfc(sqrt(x/2))`.

These are exact identities for the required cases and remove a dependency on a special-functions package.

## Random Poisson generation

Small means use Knuth's exact product algorithm. Larger means use Hoermann's PTRS transformed-rejection algorithm, avoiding the severe slowdown Knuth's method would have for large rates.

## Plotting

`bp.contour` and the plotting part of `lambda3.profile` are intentionally omitted. Their numerical outputs are retained as typed data structures so callers can plot them with their preferred environment.
