# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of the `gsl` 2.1-9 computational interface.
- Added 239 vector-oriented special-function wrappers.
- Added explicit Fortran-safe Bessel naming for case-colliding R identifiers.
- Added GSL RNG and QRNG derived-type interfaces.
- Added native Fortran strict-status handling, polynomial evaluation and complex Jacobi aliases.
- Preserved the complete supplied upstream source archive.
