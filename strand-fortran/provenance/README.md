# Provenance

- `strand-main.zip` is the exact source archive supplied for this translation.
- `SOURCE_ARCHIVE.sha256` records its SHA-256 digest.
- `ORIGINAL_FILES.sha256` records every file retained under `original/strand-0.2.3`.
- `TRANSLATED_FILES.sha256` records the translated source, tests, examples,
  documentation, license, manifest, and validation scripts.
