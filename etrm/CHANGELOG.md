# Changelog

## 1.0.2-fortran.1 - 2026-07-28

- Translated all six exported computational routines from etrm 1.0.2.
- Added typed strategy and MSFC result structures.
- Added scalar/vector CPPI and DPPI risk-percentage interfaces.
- Added Black-76 normal-CDF support without an external statistics library.
- Added LAPACK-based constrained maximum-smoothness curve solving.
- Added civil-date to relative-day helpers.
- Added strict tests, examples, API documentation, porting notes, and preserved
  MIT licensing/provenance.
