# Changelog

## 0.1.0

- Added modern Fortran 2018 modules for numerical utilities and LAPACK least squares.
- Added Black-Scholes-Merton European option values and Greeks.
- Added CRR American option pricing and European/American digital options.
- Added tree barrier pricing and continuous geometric/arithmetic Monte Carlo Asian options.
- Added European and American implied-volatility inversion and option arrays.
- Added Gregorian dates, custom calendars, day counts, business-day adjustment, and schedules.
- Added flat/zero curves, discount interpolation, deposit/futures/swap bootstrapping, and forward rates.
- Added zero, fixed-rate, and floating-rate bond analytics.
- Added Nelson-Siegel and Svensson fitting.
- Added Hagan SABR volatility and calibration.
- Added one-factor Hull-White bonds, bond options, caplets, European swaptions, and caplet calibration.
- Added strict debug/release build scripts, tests, applications, examples, license audit, provenance, and validation records.
