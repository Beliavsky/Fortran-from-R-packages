# Notice

This is an independent modern Fortran translation of the computational functionality of the R package `nls2`.

The original package source is preserved in `original/nls2-master/` for license and algorithm provenance. R-specific APIs, formulas, environments, and S3 object behavior are not part of this Fortran API.

The `CPoptim` numerical algorithm is not present in the uploaded nls2 source and is therefore not claimed as translated. See `TRANSLATION_COVERAGE.md`.
