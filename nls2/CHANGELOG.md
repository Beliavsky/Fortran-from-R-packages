# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of nls2 0.3-4.
- Added standalone Gauss-Newton NLS core.
- Added weighted fits and analytical/numerical Jacobians.
- Added brute-force/grid, random, and Latin-hypercube start search.
- Added multi-start fitting and all-result retention.
- Added partially-linear variable projection.
- Added bounded `port` compatibility path.
- Added covariance/log-likelihood/residual helpers.
- Added strict GNU Fortran tests and Windows/Linux scripts.
