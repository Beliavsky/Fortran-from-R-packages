# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of matchingR 2.0.0 computational code.
- Added Gale-Shapley marriage and college-admissions matching.
- Added student-optimal and college-optimal capacity handling.
- Added Irving stable-roommates matching, including odd-market dummy handling.
- Added top-trading-cycles matching.
- Added stability and preference/rank utilities.
- Added 0-based ordinal input compatibility with 1-based public results.
- Added strict debug, optimized, example, and randomized regression coverage.
- Documented and isolated the historical stable-roommate checker bugs.
