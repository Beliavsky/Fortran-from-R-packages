# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `miscTools` 0.6-30.
- Ported matrix insertion, symmetric/triangular conversions, medians,
  semidefiniteness, bordered-Hessian tests, R-squared, normal-density
  derivatives, standard errors, coefficient tables, and name checking.
- Added standalone Jacobi eigensolver and incomplete-beta/Student-t support.
- Documented plotting/reporting/R-object omissions explicitly.
