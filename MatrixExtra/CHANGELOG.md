# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of MatrixExtra 0.1.15 computational code.
- Reuses Matrix-fortran CSR/CSC data structures as an FPM path dependency.
- Adds COO/sparse-vector types, conversions, slicing, sparse assignment, binding,
  multiplication, elementwise operations, pattern logic, vector recycling,
  mathematical functions, norms, diagonal operations, and utilities.
- Adds strict GNU Fortran regression suite and examples.
