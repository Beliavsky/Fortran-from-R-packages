# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of CGNM 0.9.3 computational core.
- Added version-3 clustered and version-1 global CGNM iterations.
- Added CGNR, bounds, multi-objective targets, bootstrap and EBE support.
- Added non-graphical result-screening/postprocessing helpers.
- Added strict GNU Fortran regression suite and examples.
