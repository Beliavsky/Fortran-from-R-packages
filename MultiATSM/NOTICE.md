# Notice and provenance

This project is a language translation of computational routines from
`MultiATSM` version 1.5.1-2 by Rubens Moura and contributors.

Upstream project: <https://github.com/rubensmoura87/MultiATSM>

The original package declares `GPL-2 | GPL-3`. This translation therefore uses
`GPL-2.0-only OR GPL-3.0-only`. The original source snapshot is retained in
`upstream/MultiATSM-main` for attribution, verification, and license
preservation.

The Fortran API is matrix-first and is not a binary or source-compatible clone
of R's list, S3, data-frame, date, Excel, plotting, or package-data interfaces.
