# Changelog

## 3.1.2-fortran.1 - 2026-08-01

- Initial modern Fortran/FPM translation of the `sandwich` 3.1-2 computational
  core.
- Added generic score/bread covariance APIs and a weighted OLS adapter.
- Added HC, HAC, cluster, panel, bootstrap, jackknife, kernel, PAVA, and
  long-run variance algorithms.
- Added self-contained linear algebra, tests, examples, documentation, and
  retained upstream source snapshot.
