# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of tscopula 0.3.9.
- Added self-contained margins, V-transforms, pair copulas, exact ARMA Kalman
  filtering, SARMA expansion, D-vines, W-copulas, full models, fitting,
  simulation, residuals, and prediction.
- Added checked and optimized test suites, example, build scripts, API map,
  validation report, and preserved upstream/provenance archives.
