# Dependency provenance

These archives are earlier Fortran translations of R packages imported by
`tscopula`. They are retained only to document prior work and interface
comparisons. None of them is compiled or linked by this package.

The distributable library is self-contained. In particular,
`polynom-fortran-v0.1.0.zip` is GPL-2.0-only and is not combined with this
GPL-3.0-only build.
