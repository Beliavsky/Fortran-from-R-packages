# Changelog

## 0.6.0-fortran.1

- Initial modern Fortran 2018/FPM translation of cvar 0.6.
- Added quantile-, CDF-, PDF-, vector-, and matrix-based VaR/ES APIs.
- Added location-scale and log-return transformations.
- Added adaptive Gauss-Kronrod integration and CDF inversion.
- Added normal, Student-t, standardized-t, and GED numerical utilities.
- Added deterministic random generation for normal, standardized-t, and GED laws.
- Added typed GARCH(1,1) models, simulation results, and forecast results.
- Added plug-in and Monte Carlo predictive intervals.
- Corrected two transformed-ES inconsistencies documented in `PORTING.md`.
- Added strict tests, examples, API documentation, provenance files, and GPL texts.
