# Notices and attribution

## Original package

This project is a modern Fortran translation of the R package **cvar 0.6**.

- Original author and maintainer: Georgi N. Boshnakov
- Original project: `cvar`
- Original description: computation of expected shortfall and value at risk for continuous distributions, with experimental GARCH(1,1) support
- Original license declaration: `GPL (>= 2)`
- Translation license: `GPL-2.0-or-later`

The original package metadata, R source, selected tests, README, NEWS, and references are retained under `original/` for provenance. The original author has not reviewed or endorsed this translation.

## Translation

The Fortran code is a clean language port based on the supplied GPL-licensed source. It preserves the original license and attribution. Every Fortran source file carries an SPDX license identifier.
