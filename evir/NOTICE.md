# Notice

This project is a modern Fortran translation of the computational algorithms
in the R package **evir 1.7-4**, "Extreme Values in R".

Original package authors and contributors:

- Bernhard Pfaff
- Alexander McNeil, author of the original S package EVIS
- Alec Stephenson, author of the R port of EVIS

The original package metadata declares `GPL (>= 2)`. This translation is
therefore distributed under **GPL-2.0-or-later**. Original R sources, manuals,
demos, metadata, and datasets are retained under `original/evir-master/` for
provenance. No claim is made that the original authors reviewed or endorsed
this translation.
