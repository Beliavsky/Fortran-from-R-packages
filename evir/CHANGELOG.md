# Changelog

## 1.7.4-fortran.1

- Initial complete computational translation of evir 1.7-4.
- Added modern Fortran result types, explicit status codes, and FPM packaging.
- Added self-contained optimization, Hessian, matrix inversion, RNG, and
  quantile utilities.
- Added exact `xi=0` limits and support validation.
- Replaced interactive plotting functions with numeric diagnostic results.
- Corrected the GPD quantile Wald cross-covariance term.
- Added strict, optimized, independent-reference, profile, and bivariate tests.
