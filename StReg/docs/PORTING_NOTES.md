# Porting notes

## Joint model

The upstream likelihood is retained. For each usable observation, current and
lagged variables are stacked into a vector of dimension `(lag + 1) * l` and
modeled by a multivariate Student-t distribution with fixed degrees of freedom.
The scale matrix is generated by `BlockTop` from `lag + 3` symmetric factor
matrices, which guarantees positive semidefiniteness.

## Conditional model

The port partitions the fitted joint scale matrix into response and predictor
blocks and uses the standard multivariate Student-t conditional formulas.
This unifies the four R entry points and supports arbitrary positive lag
lengths without R's dimension dropping or recycling.

## Deliberate corrections

1. `Par.star` and parts of `Par.stvar` collapse lagged trend matrices in ways
   that are dimensionally reliable only for lag one or constant trends. The
   port computes the deterministic conditional mean separately for every
   observation from the fully stacked trend matrix.
2. `Students-t-test.R` uses `ncol(B1)`, the response dimension, where the
   conditional Student-t formula requires the number of conditioning
   variables. Correct behavior is the default. Set
   `streg_options%source_compatible=.true.` for the upstream convention.
3. R-squared is computed equation by equation from the actual response rather
   than from a mean over the complete data matrix.
4. The StDLM documentation mentions lag zero, but the R implementation rejects
   it. The Fortran `stdlm` also requires a positive lag; use `stlm` for the
   static model.
5. The upstream variance-coefficient report is based on the first response
   variance even for StVAR. The compatibility vector `var_coef` retains that
   definition; the complete `innovation_scale` matrix is also returned.

## Initialization and optimization

The R package starts from random values in `[0, 0.1]`. The port instead uses a
reproducible least-squares mean and residual-covariance square-root start, with
small deterministic perturbations in the remaining block factors. BFGS with
central-difference gradients is the default; Nelder-Mead is also available.

The factor representation is overparameterized, so its raw Hessian can be
singular even when conditional parameters are identified. Optional inference
uses a small documented ridge when inverting the numerical Hessian, followed
by delta-method Jacobians for conditional and variance coefficients.

## Omitted R infrastructure

R lists, column labels, `htest` objects, expression capture, data downloading,
and plotting examples are not computational requirements and are omitted.

## Reentrancy

The optimizer callback uses private module state to avoid compiler trampolines
and executable-stack requirements. Consequently, simultaneous fitting calls
from multiple threads are not supported. Independent fitted result objects are
otherwise self-contained after a call returns.
