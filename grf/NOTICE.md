# Notices and attribution

This directory is a clean-room Fortran translation of computational portions of the R package **grf 2.6.1**, Generalized Random Forests.

Upstream package metadata credits Julie Tibshirani, Susan Athey, Erik Sverdrup, Stefan Wager, Rina Friedberg, Vitor Hadad, David Hirshberg, Luke Miner, and Marvin Wright. The upstream package is distributed under GPL-3. The original package sources and metadata are retained without modification under `upstream/` for license, copyright, attribution, testing, and provenance purposes.

The maintained Fortran sources in `src/`, tests, examples, and translation documentation are distributed under GPL-3 consistently with the upstream package. No Rcpp, RcppEigen, BLAS, LAPACK, system GMP, or other separately installed numerical library is required by this translation.

This translation is not an official release of the GRF authors and does not claim byte-for-byte, RNG-for-RNG, object-model, or inference compatibility with the R/C++ implementation.
