# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of rmutil 1.1-10.
- Ported complete exported probability-distribution d/p/q/r surface.
- Ported Romberg integration and ACM TOMS 614/INTHP.
- Added adaptive and 2-D integration utilities.
- Ported RK4, matrix exponential, linear ODE solver, and Gauss-Hermite rules.
- Ported `gettvc`, `contr.mean` numerical behavior, grouped sums/means.
- Ported all 13 PK/PD mean functions.
- Preserved GPL-2-or-later licensing and upstream provenance.
- Omitted graphics, file readers, formula interpretation, and R S3 object glue.
