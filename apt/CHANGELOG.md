# Changelog

## 4.0.0-fortran.1

- Initial modern Fortran/FPM translation of apt 4.0.
- Ported all seven exported computational routines.
- Added native OLS, general linear F-tests, special-function probabilities, Ljung-Box tests, and deterministic Durbin-Watson approximation.
- Added typed results, status codes, applications, examples, and independent reference tests.
- Retained the original package source and GPL-2.0-or-later licensing.
