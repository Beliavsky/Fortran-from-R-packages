# Upstream source record

This translation was prepared from the user-supplied source archive
`KFAS-master.zip`, containing KFAS version 1.6.0.

The authoritative metadata copied from that archive is retained in:

- `provenance/KFAS-DESCRIPTION`
- `provenance/KFAS-CITATION`
- `provenance/KFAS-ChangeLog`
- `provenance/upstream-sha256.txt`

The source hashes make it possible to identify exactly which supplied upstream
computational files were used even though the Fortran files in `src/` may have
mechanical formatting and interface adaptations.
