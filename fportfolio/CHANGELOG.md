# Changelog

## 0.1.0

- Initial combined modern Fortran translation of the main computational
  `fPortfolio` surface.
- Added estimators, portfolio risk, tail risk, risk-budget, and drawdown APIs.
- Added constrained mean-variance, frontier, tangency, maximum-return,
  maximum-diversification, risk-parity, MAD, CVaR, and cardinality algorithms.
- Added rolling backtests, smoothing, transaction costs, rolling risk, and
  monitoring indicators.
- Added command-line CSV fit and backtest applications.
- Added strict debug/release builds, numerical tests, and license auditing.
