# Notice and provenance

This project is a modern Fortran translation of computational code from the
R package `rpart`, version 4.1-27.

Upstream package metadata lists:

- Terry Therneau — author
- Beth Atkinson — author and maintainer
- Brian Ripley — translator/producer of the initial R port and former maintainer

Upstream project locations include the CRAN `rpart` package and the
`bethatkinson/rpart` GitHub repository.

The upstream package declares the license `GPL-2 | GPL-3`. This translation
preserves that licensing choice. Copies of GPL version 2 and GPL version 3 are
included as `LICENSE-GPL-2` and `LICENSE-GPL-3`.

The unmodified upstream source archive contents used for this translation are
retained under `upstream/` so that algorithm provenance and parity can be
reviewed directly.

No claim is made that this project is endorsed by the upstream authors or by
the R Project.
