# API summary

Main module: `ffp_mod`.

Probability routines: `normalize_probabilities`, `crisp_probabilities`,
`exp_decay_probabilities`, `normal_kernel_probabilities`, `half_life`,
`effective_scenarios`, `relative_entropy`.

Statistics: `weighted_moments`, `weighted_empirical_stats`.

Optimization: `entropy_pool_equalities`, `entropy_pool_constrained`,
`least_info_kernel`, `fit_to_moments`, `double_decay_covariance`,
`double_decay_probabilities`.

Views: `view_on_mean`, `view_on_covariance`, `view_on_volatility`,
`view_on_correlation`, `view_on_rank`.

Sampling: `bootstrap_scenarios`.
