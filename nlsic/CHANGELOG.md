# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of nlsic 1.2.0.
- Added constrained nonlinear least-squares solver with backtracking.
- Added analytical/numerical Jacobian paths and Jacobian reuse controls.
- Added LDP, LSI, least-norm/equality-constrained LS, TLS and regularized LS.
- Added null-space/particular-solution and bound-conversion helpers.
- Added covariance and confidence-interval calculations.
- Added strict GNU Fortran regression suite and examples.
