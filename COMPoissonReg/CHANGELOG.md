# Changelog

## 0.1.0

- Initial modern Fortran 2018/FPM translation of COMPoissonReg 0.8.2.
- Port CMP, ZICMP, and ZIP distributions and moments.
- Port truncated/asymptotic/hybrid CMP normalizing constant and derivative sums.
- Add standalone raw CMP/ZICMP regression with fixed parameters and offsets.
- Add observed-Hessian covariance, AIC/BIC, residuals, equidispersion tests,
  CMP leverage/deviance, prediction helpers, and parametric bootstrap.
- Port experimental Fisher information routines.
- Preserve upstream GPL-2-or-GPL-3 licensing and source provenance.
