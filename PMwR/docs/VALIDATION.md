# Validation

The regression programs cover:

1. simple returns, weighted portfolio returns, position returns, holdings, and contributions;
2. rebalancing, dividend/split adjustment, and unit-price accounting;
3. journals, reconstructed positions, closed-trade and path P/L, trade splitting, and exposure;
4. drawdowns, contribution linking, attribution identities, and NAV statistics;
5. ISIN/SEDOL validation and Treasury 32nds conversion;
6. position and weight-driven backtesting, wealth accounting, and journal generation.

The build scripts compile every library source, test, example, and the demo in
both checked and optimized modes.
