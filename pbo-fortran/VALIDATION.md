# Validation

The project is validated with GNU Fortran 14.2.0 in Fortran 2018 mode.

Strict debug flags:

```text
-std=f2018 -Wall -Wextra -Wconversion-extra -Wimplicit-interface
-Werror -fcheck=all -fbacktrace
```

Optimized validation uses `-O2 -std=f2018 -Wall -Wextra -Werror`.

## Test programs

- `test_combinations`: binomial counts and exact lexicographic CSCV
  combinations.
- `test_metrics`: mean, sum, sample-Sharpe, and empirical Omega metrics.
- `test_pbo`: fixed independent reference for selections, average ranks,
  logits, PBO, loss probability, legacy regression fields, corrected
  degradation regression, and invalid input rejection.
- `test_analysis`: selection frequencies, empirical CDFs, upstream dominance
  difference, and integrated CDF difference.

The fixed reference case was independently calculated with Python/NumPy from
an explicitly embedded matrix rather than generated by the Fortran code under
test.

The demo and both examples are compiled and executed. The final ZIP is then
extracted into a clean directory and the same validation is repeated.

FPM was not installed in the translation environment. The source layout and
manifest use standard automatic FPM discovery and are also compiled without
nonstandard source-line-length options.
