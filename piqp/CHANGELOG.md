# Changelog

## 0.1.0

* Initial modern Fortran/FPM translation of the PIQP-R computational surface.
* Added proximal infeasible primal-dual predictor/corrector QP solver.
* Added equality, two-sided inequality, and variable-bound support.
* Added persistent model updates and PIQP-compatible result/status structures.
* Added Matrix-fortran CSC adapter.
* Added strict regression tests reproducing upstream CRAN example solutions.
