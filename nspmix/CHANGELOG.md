# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of nspmix 2.0-0.
- Added typed normal, Poisson, geometric, negative-binomial, CVPS and mlogit data models.
- Added constrained-Newton mass fitting and support-search NPMLE.
- Added semiparametric compatibility entry points and distribution utilities.
- Vendored supplied lsei-fortran dependency.
- Added strict checked regression tests and example.
