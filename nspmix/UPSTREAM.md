# Upstream provenance

Translated from CRAN package `nspmix` version 2.0-0, dated 2025-05-10.

Upstream author/maintainer: Yong Wang, University of Auckland.

Package description: nonparametric and semiparametric mixture maximum
likelihood estimation, with algorithms described in Wang (2007) and Wang
(2010), and hierarchical constrained-Newton computation described by Wang and
Taylor (2013).

The supplied dependency `lsei-fortran-v0.1.0` is a modern Fortran translation
of the R `lsei` computational core and is retained under
`src/vendor_lsei`. Its `COPYING` is retained as `COPYING.LSEI`.

The original `DESCRIPTION` and `NAMESPACE` are retained as
`UPSTREAM_DESCRIPTION` and `UPSTREAM_NAMESPACE`.
