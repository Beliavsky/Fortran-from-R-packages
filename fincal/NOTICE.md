This project is a modern Fortran translation of the computational portions of FinCal 0.6.3.

Original package:

- Title: FinCal: Time Value of Money, Time Series Analysis and Computational Finance
- Author and maintainer: Felix Yanhui Fan
- Original version: 0.6.3
- Original license declaration: GPL (>= 2)

The Fortran translation is a modified work and is marked as such. It omits plotting and network/data-retrieval functions. Original computational R source files and package metadata are retained in `original/`.
