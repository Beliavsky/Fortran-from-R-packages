# Omitted original functions

The following FinCal functions were intentionally not translated:

- plotting: `candlestickChart`, `lineChart`, `lineChartMult`, `volumeChart`
- network/data retrieval: `get.ohlc.google`, `get.ohlc.yahoo`, `get.ohlcs.google`, `get.ohlcs.yahoo`

They remain available in the upstream R package but are outside this project's computational, self-contained scope.
