# Changelog

## 0.1.0

Initial modern Fortran/FPM translation.

* Native feasible working-set QP solver with Phase-I feasibility.
* QProblem/QProblemB/SQProblem-style model and hotstart API.
* ROI objective/constraint conversion.
* Hessian types, options, statuses and diagnostics.
* Unbounded zero-Hessian LP detection.
* Six strict regression programs including all three upstream ROI tests.
