# Changelog

## 0.1.0

- Initial modern Fortran/FPM core translation of survival 3.8-9.
- Added right/counting-process survival curves, Cox PH, AFT models,
  Aalen-Johansen, log-rank, concordance, Fine-Gray expansion, splitting,
  pseudo-values, and spline penalty support.
- Integrated the user-supplied splines-fortran v0.1.0 as a local FPM dependency.
- Added strict compiler regression suite and examples.
