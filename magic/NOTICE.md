# Notice and provenance

This project is a modern Fortran translation of computational routines from:

- **magic: Create and Investigate Magic Squares**
- Upstream version: **1.6-1-1**
- Author and maintainer: **Robin K. S. Hankin**
- Upstream repository: `RobinHankin/magic`
- Upstream declared license: **GPL-2**

The complete supplied upstream source tree is retained in
`upstream/magic-master`. The modern Fortran organization, interfaces, tests,
and documentation are translation work. No claim is made that generated
square orientations always match R byte-for-byte when several mathematically
equivalent constructions exist.
