# Changelog

## 1.6.1 - 2026-08-01

- Initial modern Fortran/FPM translation of the computational core of
  `magic` 1.6-1-1.
- Added arbitrary-rank integer tensors and array transformations.
- Added square, panmagic, hypercube, Latin/incidence, Hadamard, SAM, and
  multiplicative-magic algorithms.
- Added six regression tests, five examples, a demo, and portable GNU Fortran
  validation scripts.
