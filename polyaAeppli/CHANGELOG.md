# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `polyaAeppli` 2.0.2.
- Ported all four exported distribution functions.
- Ported internal log-PMF, log-CDF, upper-tail, and reverse-tail recurrences.
- Added standalone Poisson/geometric RNG algorithms.
- Added integer-bisection quantiles without a `qgamma` dependency.
- Added scalar and R-style recycling vector interfaces.
