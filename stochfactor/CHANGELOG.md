# Changelog

## 0.1.0

- Created one combined modern Fortran project from `stochvol` 3.2.9 and
  `factorstochvol` 1.1.2.
- Added univariate Gaussian, Student-t, leverage, and regression SV simulation.
- Added auxiliary-mixture and general latent-state MCMC paths.
- Added parameter, regression, Student-t scale, residual, prediction, and rolling
  forecast computations.
- Added factor-SV simulation, covariance/correlation calculations, initialization,
  identification, fitting, prediction, likelihood scoring, and diagnostics.
- Added custom loading restrictions and zero-factor support.
- Added Normal-Gamma global/local shrinkage updates.
- Added Woodbury precision and log-determinant computations.
- Added demo and CSV applications.
- Added debug and optimized validation with warnings treated as errors.
- Added machine-checked GPL-2.0-or-later headers.
