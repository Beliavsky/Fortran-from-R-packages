# Independent R fixture provenance

`test/r_reference.inc` contains binary64 decimal fixtures generated by the
actual **R 4.5.0 (2025-04-11)** interpreter with the official **BurStFin 1.3**
package, on 2026-10-12. The fixture script verifies the installed version.
There are no calls to the Fortran translation in the generator.

From the package directory, run:

```sh
Rscript reference/generate_fixtures.R test/r_reference.inc
```

The script generates deterministic trigonometric input data, records these
inputs as constants, calls all six mapped R functions, and writes finite
outputs at 17 significant digits. Thus FPM tests do not depend on R, system
BLAS, RNG state, local data files or a working directory other than normal
FPM operation. Covariances and variance fractions avoid nonidentifiable
SVD/eigenvector sign comparisons.

Expected warnings for time weighting in compatibility mode and normalization
of signed benchmark holdings are retained in the external audit run log.
No plotting code is exercised. `factor.model.stat` comparisons include full,
systematic, specific, uniqueness, standard-deviation and cumulative-variance
outputs, zero iterations and explicit factor bounds/floors, plus all-missing
rows, sparse assets, missing-count-specific regressions and replaced standard
deviations. Shrinkage comparisons cover automatic/explicit intensities,
centering, nonuniform/zero weights, compatibility scaling, volatility shrinkage,
missingness and eigenvalue floors. Separate Fortran analytic/property tests
exercise rank deficiency, constants, invalid values and extreme scales.
