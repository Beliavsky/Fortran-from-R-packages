# Changelog

## 0.1.0 - 2026-08-03

- Initial modern Fortran/FPM translation of the RobStatTM computational core.
- Added robust loss, scale, regression, DCML, RFPE, robust logistic, robust scatter, projection initialization, and robust PCA modules.
- Vendored compatible robustbase and rrcov Fortran dependencies.
- Added R-name compatibility wrappers, five runtime tests, a regression example, checked/optimized GNU Fortran build scripts, source/API maps, and license provenance.
