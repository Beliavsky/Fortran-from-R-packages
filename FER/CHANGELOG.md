# Changelog

## 0.94.0-fortran.1

- Translated all exported computational routines from FER 0.94.
- Added a standard FPM package layout and `fpm.toml` manifest.
- Added Bachelier and Black-Scholes implied-volatility solvers in Fortran.
- Added self-contained gamma and noncentral chi-square numerical routines.
- Added demonstration, example, and regression-test targets.
- Retained the original R package under `original/`.
- Preserved the original GPL-2.0-or-later licensing declaration.
