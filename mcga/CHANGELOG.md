# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of mcga 3.0.9.
- Added single- and multi-objective native MCGA engines.
- Added byte conversion and all byte mutation/crossover primitives.
- Added all mcga-specific GA operator-library routines.
- Added tests, examples, strict GNU Fortran validation scripts, API notes, and
  upstream provenance tree.
