# Changelog

## 2.2.1-fortran.1

- Added a typed modern Fortran translation of all 26 public R entry points.
- Added projected BFGS, Nelder-Mead, pattern-search, penalty-constrained, and
  deterministic multistart solver backends.
- Added central finite-difference gradients/Jacobians and derivative checking.
- Added four tests, three examples, a demo, and FPM metadata.
- Retained the upstream R wrapper sources and LGPL-3.0-or-later license.
