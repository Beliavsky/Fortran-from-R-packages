# Changelog

## 2.0.1 - Fortran translation

- Initial modern Fortran/FPM translation of FatTailsR 2.0.1 computational
  routines.
- Added Kiener distributions, tail-risk measures, moments, parameter
  conversions, quantile estimators, K4 fitting, and return utilities.
- Added strict numerical test suite, demonstration program, and fitting
  example.
- Preserved GPL-2.0-only licensing and original citation metadata.
