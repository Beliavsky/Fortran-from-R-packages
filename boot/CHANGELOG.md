# Changelog

## 0.1.0

Initial modern Fortran/FPM computational-core translation of R `boot` 1.3-32.

Includes resampling arrays, generic weighted bootstrap replication, confidence
intervals, influence values, exponential tilting, importance sampling,
bootstrap envelopes, block-bootstrap indices, empirical-likelihood kernels,
revised simplex LP, simple multinomial saddlepoints, censored-resampling
primitives, GLM diagnostics, and nested-correlation bootstrap calculations.
