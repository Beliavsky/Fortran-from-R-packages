# Changelog

## 0.1.0 - 2026-07-28

Initial modern Fortran/FPM translation of the computational algorithms in NMOF 2.12-0.

- Added callback-driven DE, PSO, GA, local search, simulated annealing, threshold accepting, greedy search, grid search, and restart optimization.
- Added fixed-income, term-structure, option, characteristic-function, and Fourier-pricing routines.
- Added minimum-variance, mean-variance, maximum-Sharpe, tracking, ERC, CVaR, and MAD portfolio methods.
- Added GBM, Brownian bridge, random-return, correlated-resampling, and CPPI simulations.
- Added quadrature, root solving, matrix repair, drawdown, PBO, moment, and risk-contribution utilities.
- Added active-set quadratic programming and projection routines using BLAS/LAPACK.
- Added four test programs, a demonstration application, two examples, and reproducible strict/optimized build scripts.
- Retained the complete original NMOF package tree for provenance.
