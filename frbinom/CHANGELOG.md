# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `frbinom` 1.0.0.
- Ported all eight exported computational functions.
- Added shared PMF/CDF table kernels.
- Added vector and upper-tail interfaces.
- Added inverse-CDF RNGs using Fortran's intrinsic random-number generator.
- Added strict regression, binomial-limit, family-II, quantile, and RNG tests.
