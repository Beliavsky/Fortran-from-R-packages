# Changelog

## 0.1.0

- Initial combined modern Fortran translation of the computational `fCopulae` surface.
- Added all 22 Archimedean families with generators, inverses, CDFs, densities, simulation, dependence measures, tail coefficients, and fitting.
- Added seven elliptical families with marginal and copula probability functions, simulation, dependence measures, and fitting.
- Added five official extreme-value families with Pickands functions, probability functions, simulation, dependence measures, and fitting.
- Added empirical copula grids/densities, Frechet copulas, Marshall-Olkin CDF, and Debye functions.
- Added strict debug and optimized build workflows, three regression suites, applications, sample CSV data, API mapping, provenance, and license auditing.
- Corrected the invalid original Tawn default and the original Marshall-Olkin branch-selection formula.
