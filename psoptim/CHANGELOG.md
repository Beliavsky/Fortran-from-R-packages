# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of `psoptim` 1.0.
- Ported the global-best particle swarm optimizer.
- Added deterministic standalone RNG.
- Added compatibility controls for original initialization and velocity
  quirks.
- Added fitness histories, evaluation counts, and diagnostic final states.
- Added two examples and four regression tests.
- Preserved GPL-2.0-or-later licensing and original source provenance.
