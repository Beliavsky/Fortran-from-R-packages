# Notices

This package is a modern Fortran computational port of the R package `mize`,
written by James Melville and distributed under the BSD 2-Clause License.

The original package documentation credits algorithmic sources including
Nocedal and Wright, Hager and Zhang, Mark Schmidt's `minFunc` routines, Carl
Edward Rasmussen's line-search code, and Dianne O'Leary's translation of the
More-Thuente/MINPACK line search. Those attributions remain relevant to the
translated algorithms. The original source tree is retained under
`original_source/mize-master` for provenance and detailed references.
