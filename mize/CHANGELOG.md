# Changelog

## 0.1.0

- Initial modern Fortran computational port.
- Added one-shot and stateful APIs.
- Added all exposed optimization direction families and CG update formulas.
- Added safeguarded Wolfe, Armijo, bold-driver, and constant step methods.
- Added exact and finite-difference Newton information.
- Added momentum schedules, adaptive restart, DBD, progress, cancellation, and
  gradient diagnostics.
