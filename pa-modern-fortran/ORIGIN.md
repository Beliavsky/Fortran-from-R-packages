# Origin and licensing

This project translates the computational routines of:

- R package: `pa`
- Version in the attached source: 1.2-4
- Authors: Yang Lu and David Kane
- Package description: Performance Attribution for Equity Portfolios
- Original license declaration: `GPL-2`

The translation therefore uses:

```text
SPDX-License-Identifier: GPL-2.0-only
```

`LICENSE` contains the complete GNU General Public License version 2 text. Every Fortran source, application, example, and test file contains the GPL-2.0-only SPDX identifier and license notice. The original source archive is retained under `original/pa-master.zip` for provenance.

The translation is independently organized as modern Fortran modules and does not reproduce R's S4 classes, plotting code, or data-frame/formula infrastructure.
