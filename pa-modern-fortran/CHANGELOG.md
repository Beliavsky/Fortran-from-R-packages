# Changelog

## 0.1.0

- Added complete single- and multi-period Brinson attribution.
- Added category-level allocation, selection, and interaction effects.
- Added arithmetic, geometric, and linking aggregation.
- Added regression-based attribution with LAPACK least squares.
- Added mixed categorical/numeric design-matrix construction.
- Added single- and multi-period categorical and quintile exposures.
- Added reusable plain-array result types.
- Added simulation/example programs and a CSV application.
- Added strict debug and optimized validation workflows.
- Preserved GPL-2.0-only licensing in all Fortran files.
