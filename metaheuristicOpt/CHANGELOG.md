# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of metaheuristicOpt 2.0.0.
- Added all 21 optimization engines.
- Added `metaopt` and `metaopt_many` dispatch interfaces.
- Added common control/result derived types and deterministic RNG.
- Added minimization/maximization support, bound handling, history, and
  evaluation accounting.
- Added all six Differential Evolution strategies.
- Added package benchmark/helper functions.
- Added legacy-compatibility switch for observable upstream algorithm quirks.
- Added five regression test programs and two examples.
- Preserved GPL-2.0-or-later licensing and complete original source provenance.
