# Changelog

## 0.1.0

- Initial modern Fortran translation of `lgarch` 0.7 computational routines.
- Added vector and matrix lag/difference utilities.
- Added arbitrary-order univariate log-GARCH simulation.
- Added univariate ARMA recursion and zero-return treatment.
- Added LS, Gaussian QML, and CEX2 fitting with optional mean correction and
  exogenous regressors.
- Added fitted volatility, residual, likelihood, Hessian, and covariance
  calculations.
- Added multivariate Normal generation.
- Added CCC multivariate log-GARCH simulation, VARMA recursion, Gaussian
  likelihood, fitting, fitted values, residuals, Hessians, and covariance
  calculations.
- Added custom starts, bounds, objective penalties, and optimizer controls.
- Added demonstration, CSV fitting application, examples, tests, licensing
  audit, API mapping, provenance, and validation documentation.
