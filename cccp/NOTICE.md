# Notice and provenance

This project is a clean modern-Fortran translation of `cccp` version 0.3-3.

Original package author and maintainer:

- Bernhard Pfaff

The R package states that parts of its algorithms were ported from CVXOPT and
lists Lieven Vandenberghe, Martin Andersen, and Joachim Dahl as CVXOPT copyright
holders. The complete original package source and metadata are retained in
`original/`.

The original package is licensed under GPL version 3 or later. This translation
uses the same GPL-3.0-or-later licensing. SPDX identifiers are present in the
Fortran sources, and the GPL version 3 text is included in `LICENSE`.
