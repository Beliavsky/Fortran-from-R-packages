# Notice

This project is a modern Fortran translation of the computational algorithms in
ACDm 1.1.0, originally written by Markus Belfrage.

The original package is distributed under GPL (>= 3). This translation is
therefore distributed under GPL-3.0-or-later. The complete original package
snapshot is retained in `original/` for attribution and provenance.

The translation preserves the mathematical methods and public numerical scope,
but it is not an official release by the original author. R object classes,
interactive graphics, data-frame dispatch, and package-specific console output
are not reproduced.
