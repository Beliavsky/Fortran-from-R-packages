# Changelog

## 1.1.0-fortran

- Translated all 13 ACD-family model recursions.
- Translated all ten native duration distributions.
- Added generic distribution and model APIs.
- Added bounded maximum-likelihood estimation, numerical scores, Hessian,
  covariance estimators, bootstrap errors, and forecasting.
- Translated trade, price, and volume duration construction.
- Translated cubic-spline, smooth-spline, super-smoother, and Flexible Fourier
  Form diurnal adjustment.
- Translated residual transformations and the three LM specification tests.
- Added numeric replacements for ACF, density, QQ, hazard, rolling, and
  likelihood-profile plots.
- Corrected and documented inconsistencies between original likelihood,
  simulation, and wrapper code.
- Added FPM packaging, examples, strict tests, and retained original provenance.
