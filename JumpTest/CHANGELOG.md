# Changelog

## 1.1.0-fortran.1

- Initial modern Fortran/FPM translation of JumpTest 1.1.
- Added all five stochastic-volatility simulators.
- Added BNS, Amin, and Amed jump statistics.
- Added period testing, p-value combination, six pooling methods, and BH FDR.
- Added self-contained RNG and probability routines.
- Added explicit status/result types, tests, examples, and validation scripts.
- Documented and corrected malformed upstream jump-size sampling calls.
