# Changelog

## 0.1.0 - 2026-08-03

- Initial modern Fortran translation of Spillover 0.1.1.
- Added self-contained VAR(p) OLS estimation and MA recursion.
- Added generalized and orthogonalized FEVDs.
- Added exact and sampled ordering averages.
- Added total, directional, net, pairwise, and rolling connectedness APIs.
- Added source-compatible modes for two upstream implementation inconsistencies.
- Added five checked and optimized runtime tests and one example.
