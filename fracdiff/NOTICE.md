# Notice and provenance

This project is a modern Fortran translation of `fracdiff` 1.5-4.

Original package authors and contributors listed in `DESCRIPTION` include
Martin Maechler, Chris Fraley, Friedrich Leisch, Valderio Reisen, Artur
Lemonte, and Rob Hyndman. The original likelihood and simulation code states:

- copyright 1991 Department of Statistics, University of Washington;
- written by Chris Fraley.

Later R maintenance and enhancements are attributed in the retained source and
package metadata. The complete unmodified package source used for the port is
stored under `original/fracdiff-1.5-4/`.

The original package declares `GPL (>= 2)`. The Fortran translation is
`GPL-2.0-or-later` and retains copyright and license notices in source files.
