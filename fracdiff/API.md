# API reference

All real-valued calculations use `dp = kind(1.0d0)` from `fracdiff_kinds`.
The umbrella module is:

```fortran
use fracdiff
```

## Model estimation

```fortran
model = fracdiff_fit(x, nar, nma, ar_initial, ma_initial, &
                     d_tolerance, d_range, h, m_terms, trace)
```

Returns a `type(fracdiff_model)` containing:

- `d`, `ar`, and `ma`
- estimated mean and innovation standard deviation
- log likelihood and minimized residual norm
- covariance, correlation, Hessian, and standard errors
- residuals and fitted values
- optimization counts and status information

Defaults reproduce the source interface where applicable:

- `nar = 0`
- `nma = 0`
- initial AR and MA values equal zero
- `d_range = [0, 0.5]`
- `d_tolerance = epsilon(1.0_dp)**0.25`
- `m_terms = 100`

## Covariance recomputation

```fortran
call fracdiff_var(x, model, h, status)
```

Recomputes the numerical Hessian, covariance, standard errors, and correlation
matrix without refitting the model.

## Simulation

```fortran
simulation = fracdiff_sim(n, d, ar, ma, mean_value, n_start, &
                          back_compatible, allow_zero_start, &
                          innovations, start_innovations, seed, &
                          standard_deviation)
```

Returns `type(fracdiff_simulation)`. Innovations may be supplied explicitly,
or generated by the included Park-Miller/Box-Muller generator.

The low-level source recursion is also public:

```fortran
call fractional_arma_filter_simulation(innovations, ar, ma, d, mean_value, &
                                       series, status)
```

`innovations` must contain at least `size(series) + size(ma)` values.

## Fractional differencing

```fortran
call diffseries(x, d, dx, status)
call diffseries_direct(x, d, dx, status)
call fractional_weights(n, d, weights, status)
```

`diffseries` uses FFT convolution. `diffseries_direct` retains the original
quadratic convolution for verification and small inputs. Both subtract the
sample mean before applying the fractional filter, as the R package does.

## Long-memory estimators

```fortran
gph = fd_gph(x, bandwidth_exponent)
sperio = fd_sperio(x, bandwidth_exponent, beta)
```

Both return `type(fractional_d_estimate)` with:

- `d`
- `sd_asymptotic`
- `sd_regression`
- `status` and `message`

Defaults are `bandwidth_exponent = 0.5` and, for Sperio, `beta = 0.9`.

## Model methods

```fortran
coefficients = fracdiff_coefficients(model)
intervals = fracdiff_confint(model, level)
summary = summarize_fracdiff(model)
aic = fracdiff_aic(model)
bic = fracdiff_bic(model)
```

Coefficient ordering is `d`, then AR terms, then MA terms.

## Lower-level numerical procedures

```fortran
call haslett_raftery_filter(x, d, m_terms, has_arma, y, sum_log_v, mean, status)
call arma_residuals(y, ar, ma, residuals, status)
call arma_residual_jacobian(y, ar, ma, residuals, jacobian, status)
call conditional_arma_series_residuals(x, ar, ma, residuals, fitted, status)
call polynomial_multiply(a, b, product)
call polynomial_roots(coefficients, roots, status)
root_modulus = minimum_ar_root_modulus(ar, status)
```

The polynomial coefficient ordering is ascending power: constant term first.
