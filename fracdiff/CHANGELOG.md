# Changelog

## 1.5.4-fortran.1

- Added the complete Haslett-Raftery ARFIMA(p,d,q) likelihood implementation.
- Added Brent profiling over `d` and Levenberg-Marquardt ARMA estimation.
- Added numerical Hessian, covariance, correlation, standard errors, and
  covariance recomputation.
- Added exact fractional simulation with ARMA filtering, burn-in, supplied
  innovations, and deterministic RNG support.
- Added FFT and direct fractional differencing.
- Added GPH and Sperio estimators.
- Added coefficient, confidence-interval, summary, AIC, and BIC helpers.
- Added polynomial utilities, examples, strict tests, provenance, and complete
  GPL license texts.
