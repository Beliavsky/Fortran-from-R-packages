# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of kdensity 1.2.0.
- Added all built-in kernel formulas.
- Added parametrically guided density fitting and transformed normalization.
- Added common parametric starts and custom callback interfaces.
- Added JH, RHE, HS, nrd0, nrd, and UCV bandwidth selection.
- Added five deterministic tests and an example.
