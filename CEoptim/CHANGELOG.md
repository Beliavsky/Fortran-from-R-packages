# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of CEoptim 1.3 computational code.
- Added continuous, categorical, and mixed Cross-Entropy optimization.
- Added maximization, elite smoothing, convergence/no-improvement stopping,
  state history, and package-compatible evaluation accounting.
- Added linearly constrained continuous sampling.
- Added truncated multivariate-normal accept/reject and Gibbs algorithms.
- Added native truncated-normal, multivariate-normal, and Dirichlet sampling.
- Added standalone reproducible RNG.
- Added regression tests and FPM examples.
- Preserved GPL-2.0-or-later licensing and original package provenance.
