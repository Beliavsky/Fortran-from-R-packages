# Origin and translation scope

The source archive supplied for this translation identifies itself as
`portvine` version `1.0.3.9000`. The FPM package uses numeric version `1.0.3`.

The translation targets the package's numerical workflow:

1. rolling ARMA-GARCH marginal estimation;
2. probability-integral-transform residuals;
3. partial-correlation D-vine ordering;
4. rolling parametric vine fitting;
5. unconditional or one-/two-variable conditional simulation;
6. inverse marginal transformation and weighted portfolio returns;
7. empirical VaR and three expected-shortfall estimators;
8. realized-return alignment.

The retained R source is provenance only and is not compiled by FPM.
