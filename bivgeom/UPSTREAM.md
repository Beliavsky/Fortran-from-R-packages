# Upstream provenance

This project translates the computational code of:

- `bivgeom` 1.0
- Author/Maintainer: Alessandro Barbiero
- Title: Roy's Bivariate Geometric Distribution
- Upstream `DESCRIPTION`: `License: GPL`

The unmodified source tree supplied for translation is retained in the
`upstream/` directory.

Primary model reference from the package documentation:

D. Roy (1993), "Reliability measures in the discrete bivariate set-up and
related characterization results for a bivariate geometric distribution",
Journal of Multivariate Analysis 46(2), 362-373.
