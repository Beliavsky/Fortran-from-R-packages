  Use these translation-coverage conventions:

  - Count distinct exported computational R functions. Exclude plotting,
    printing, formatting, dataset, data-download, interactive-display, and
    presentation-only functions. Exclude internal helpers and functions that
    merely dispatch to another package. Include an exported fitting or
    computational function even when part of its R interface is omitted.
  - Include explicitly exported S3 methods when they perform a computational

  - Set r_functions_total to the number of functions in that coverage basis.

    in untranslated_r_functions. Use an empty array when none are untranslated.
  - Add one [[extra.translation.function]] entry for every distinct R function
    with a meaningful complete, substantial, or partial translation. Count each
    R function once even when it maps to several Fortran procedures.
  - Set r_functions_translated to the number of function mapping entries and set
    frac_functions_translated to r_functions_translated / r_functions_total.
    Ensure the integers, fraction, mapping entries, and untranslated list agree.
  - Preserve the exact case and punctuation of each R function in r_name. Always
