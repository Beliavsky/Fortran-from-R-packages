# Changelog

## 0.2.0 - Modern Fortran translation

- Translated all six exported computational estimators.
- Added Student-t EM/PX-EM, missing-data imputation, observation weights, and
  factor-analysis covariance constraints.
- Added skewed-t EM/PX-EM with self-contained real-order Bessel K functions.
- Added OPP, POP, MLE, cumulant, kurtosis, Hill, and Pareto tail estimators.
- Added FPM packaging, tests, examples, documentation, and strict compiler
  scripts.
- Preserved GPL-3.0-only licensing and original computational sources.
