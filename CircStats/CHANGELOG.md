# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational translation of CircStats 0.2-7.
- Added circular descriptive statistics, distributions, RNGs, uniformity and
  homogeneity tests, regression, MLEs, change-point calculations and bootstrap CIs.
- Embedded the exact upstream Rao spacing critical-value table.
- Corrected the undefined `c` reference in skewed alpha=1 stable simulation.
- Corrected cardioid rejection sampling for negative concentration.
- Added stable limiting behavior for zero-concentration parameter cases.
- Added seven strict numerical test programs and an example.
