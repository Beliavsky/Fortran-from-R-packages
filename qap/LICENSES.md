## qap and this translation

The attached R package `qap` 0.1-2 declares `License: GPL-3` in its
`DESCRIPTION`. The translated Fortran code is distributed under GPL-3.0-only.
The full GNU GPL version 3 text is provided in `LICENSE`.

Original authorship/copyright metadata from the package is retained under
`original/qap-master/`, including the `DESCRIPTION`, source files, README, and
QAPLIB data distributed by that package.

## QAPLIB data

The original package distributes copies of QAPLIB problem and solution files.
This translation retains those files unchanged for compatibility and
regression testing and does not make an additional licensing claim over them.
See the original package documentation and QAPLIB references for provenance.
