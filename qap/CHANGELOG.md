# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of qap 0.1-2.
- Ported the Burkard-Rendl simulated-annealing QAP heuristic.
- Ported the package QAP objective and QAPLIB reader.
- Added a standalone reproducible RNG and restart handling.
- Added O(n) symmetric-QAP swap-delta API.
- Added typed controls/results and solver diagnostics.
- Retained all bundled QAPLIB instances and complete original package sources.
- Added five regression tests and two examples.
