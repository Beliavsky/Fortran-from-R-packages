# Changelog

## 0.1.0 - 2026-07-25

- Initial modern Fortran/FPM translation of the computational surface of R
  package `sde` 2.0.21.
- Added exact OU, GBM, and CIR laws and simulators.
- Added Euler, Milstein, second-order Milstein, KPS, Ozaki, Shoji,
  conditional-law, exact acceptance, and bridge simulation.
- Added local density approximations, Hermite and Pedersen likelihoods,
  estimating functions, GMM, AIC, divergence tests, kernel estimators,
  changepoints, and Markov-operator distances.
- Added dependency-free numerical support and automated tests.
- Preserved GPL-2.0-or-later licensing and upstream metadata.
