# Changelog

## 0.1.0

- Initial modern Fortran/FPM computational port of mlr 2.19.3.
- Added native measures, resampling, preprocessing, SMOTE, baseline learners,
  tuning, feature selection, threshold tuning and callback evaluation.
- Integrated supplied survival-fortran for Cox, concordance and Kaplan-Meier.
- Catalogued the 150 external R learner adapters instead of misrepresenting
  third-party learner implementations as mlr source code.
