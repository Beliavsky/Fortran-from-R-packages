# Changelog

- Initial modern Fortran/FPM translation of RPEGLMEN 1.1.4.
- Added exponential and Gamma elastic-net GLMs.
- Added joint Gamma shape estimation, regularization paths, and repeated
  balanced cross-validation.
- Added source-compatible options for the C++ proximal update and validation
  metric.
- Added checked and optimized tests, example, provenance, and license files.
