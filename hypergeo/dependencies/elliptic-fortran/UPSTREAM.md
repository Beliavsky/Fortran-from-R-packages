# Upstream provenance

This project translates the computational code of the R package `elliptic`.

- Package: `elliptic`
- Upstream version: 1.5-1
- Author/maintainer: Robin K. S. Hankin
- Upstream license: GPL-2
- Upstream title: Weierstrass and Jacobi Elliptic Functions

The original `DESCRIPTION`, `README.md`, `CITATION`, and computational R source are
retained under `upstream/` for provenance and license/audit purposes.

The mathematical terminology and many verification values in the tests follow
Abramowitz and Stegun as in the upstream package.  The original package citation is:

Robin K. S. Hankin (2006), "Introducing elliptic, an R package for elliptic and
modular functions", Journal of Statistical Software 15(7).
