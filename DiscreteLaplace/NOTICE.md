# Notice

`DiscreteLaplace-fortran` is a modern Fortran translation of the computational
code in R package `DiscreteLaplace` 1.1.1.

Original authors: Alessandro Barbiero and Riccardo Inchingolo.
The original package is retained verbatim under `upstream/`.

The Fortran translation changes language/runtime infrastructure but does not
claim authorship of the underlying statistical methods.
