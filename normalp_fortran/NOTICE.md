# Notice

This project is a modern Fortran translation of the computational routines in
`normalp` version 0.7.2.1.

Upstream package:
- Title: Routines for Exponential Power Distribution
- Author/Maintainer: Angelo M. Mineo
- Upstream license declaration: GPL

The original package DESCRIPTION is retained as `UPSTREAM-DESCRIPTION`.
This translation is intended to preserve the upstream GPL licensing; it is not
a relicensing of the original work.

Plotting, graphics, R formula/S3 presentation code, and documentation-only
wrappers are omitted. Numerical algorithms are translated or independently
implemented to provide equivalent functionality in standard Fortran.
