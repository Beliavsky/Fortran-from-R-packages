# Validation

Compiler used during translation:

```text
gfortran 14.2.0
```

Strict flags:

```text
-std=f2018 -Wall -Wextra -Werror -Wimplicit-interface -fcheck=all -O0
```

## Fortran regression tests

Four regression programs are included:

1. `test_reference_values` checks all 28 functions at a fixed 10-dimensional
   mixed-sign point against values generated by the original C source.
2. `test_optima` evaluates all 28 functions at the first official shift vector
   and checks the published objective offsets.
3. `test_dimensions` loads and evaluates every supported dimension and checks
   rejection of an unsupported dimension.
4. `test_batch_status` checks batch/scalar agreement and invalid-problem status.

All four pass with the strict flags above.  Both example programs also compile
and run successfully.

## Cross-language C comparison

For validation, the supplied `src/test_func.c` was compiled with a tiny
standalone compatibility stub for the R `error()` call.  The original C and the
Fortran translation were evaluated at the same deterministic mixed-sign point
for every combination of:

- 28 benchmark functions, and
- 12 supported dimensions.

That is **336 cross-language function/dimension comparisons**.

The maximum observed relative discrepancy was approximately
`9.2e-14`, attributable to floating-point expression/order differences.  No
case exceeded `1e-11` relative error.

A separate 2/5/10-dimensional sweep produced a worst relative discrepancy of
about `1.3e-15`.

## Source portability

- No translated `.f90` line exceeds 132 columns.
- The library compiles with `-Werror=implicit-interface`.
- No nonstandard free-form line-length flag is required.
- The default numerical core requires no BLAS/LAPACK library.
