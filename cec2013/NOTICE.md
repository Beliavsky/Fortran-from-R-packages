# NOTICE

This project is a modern Fortran translation of the computational code in the
R package `cec2013` version 0.1-5.

The upstream package declares `GPL (>= 3)`.  The translated source is therefore
distributed under GPL-3.0-or-later.  The complete supplied upstream source is
retained under `original/cec2013-master/`.

The benchmark implementation originates from the CEC 2013 test-function suite
by Jane Jing Liang.  The R package wrapper was authored by Mauricio
Zambrano-Bigiarini and Yasser Gonzalez-Fernandez.  See the upstream DESCRIPTION,
source comments, and CITATION file for the original attribution.

The numerical instance files in `data/` are copies of the upstream package's
`inst/extdata/` files and are required to reproduce the official rotations and
shifts.
