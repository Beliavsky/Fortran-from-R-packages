# Porting notes

## R lists and matrices

R lists are represented by typed Fortran result structures. R matrices are
passed as ordinary rank-two arrays with observations in rows and variables in
columns. Subsets are integer 0/1 matrices rather than character labels.

## Native C kernels

The original `ind_functionsR.c` algorithms were translated directly into
Fortran array operations. Regression tests compare against values generated by
the original C code for:

- `estdep`;
- `stats_nonserial`;
- `stats_serial`;
- `stats_serialVectors`;
- `Stat_A`.

The original serial multiplier formulas index the first lag's centered kernel
while applying circular index shifts. This apparently unusual detail is
retained because it is required to reproduce the upstream implementation.

## Bootstrap and parallelism

The R package optionally uses `parallel`, `doParallel`, and `foreach`. The
Fortran port performs the same Gaussian multiplier calculations sequentially
with a deterministic portable random-number generator. Applications can run
independent seeds in parallel outside the library.

The upstream binary-margin serial path uses a special quadratic-form
calibration through `survey::pchisqsum`. The Fortran public test uses the common
multilinear multiplier-bootstrap path for binary data as well. The underlying
binary data remain supported, but p-values may differ from that specialized R
branch.

## Copula simulation

The R package delegates parameter inversion and conditional quantiles to the
`copula` package. The Fortran port implements Kendall-tau inversion internally.
Gaussian, Student, Clayton, and FGM transitions use direct formulas. Frank,
Gumbel, Joe, and Plackett transitions use their analytic copula CDFs with
numerical differentiation and bisection of the conditional CDF. This is
self-contained but slower than specialized copula-library routines.

## Probability functions

Normal and Student quantiles, incomplete gamma/beta calculations, Poisson and
negative-binomial quantiles, and chi-square tails are implemented locally.
They are intended for the statistical ranges used by this package rather than
as a general replacement for a full special-functions library.

## Plotting and data objects

`AutoDep`, `Dependogram`, and `DependogramZ` are plotting-only and are not
compiled. Bundled `.rda` data are retained under `original/data` but are not
parsed by the Fortran library.
