# Notices

This project translates the computational core of INFOSET 4.1.1 by Gloria
Polinesi, Francesca Mariani, and Maria Cristina Recchioni. The upstream package
states `GPL (>= 2)`.

The two-normal EM implementation is adapted from the GPL-2.0-or-later
`mixtools-fortran` translation of `mixtools`. The quadratic-programming modules
are adapted from the GPL-2.0-or-later `quadprog-fortran` translation of the
Goldfarb-Idnani code in R package `quadprog`.

The combined project is distributed under GPL-2.0-or-later. Original package
metadata, computational R code, selected documentation, tests, and dependency
sources are retained under `original/` for attribution and comparison.
