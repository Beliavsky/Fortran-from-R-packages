# Changelog

## 5.0.0-fortran.1

- Initial modern Fortran/FPM translation of the `glmnet` 5.0 computational core.
- Added Gaussian, binomial, Poisson, multinomial, multiresponse Gaussian, and
  Cox regularization paths.
- Added cross-validation, prediction, relaxed fitting, assessment, survival
  diagnostics, CSC conversion, missing-value utilities, examples, and tests.
- Preserved upstream source and GPL-2 licensing material.
