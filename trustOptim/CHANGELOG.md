# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of trustOptim 0.8.7.4.
- Added SR1, BFGS, and sparse-Hessian trust-region optimizers.
- Added native lower-triangle sparse symmetric matrix storage.
- Added Steihaug preconditioned CG and trust-radius boundary handling.
- Added identity, BFGS Cholesky, and sparse modified-Cholesky preconditioning.
- Added exported binary-choice objective, gradient, and Hessian computations.
- Added strict regression tests and examples.
