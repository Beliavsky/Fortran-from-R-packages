# BiasedUrn-fortran

Modern Fortran/FPM translation of the computational code in CRAN package
**BiasedUrn 2.0.12** by Agner Fog.

BiasedUrn implements Fisher's and Wallenius' noncentral hypergeometric
models in both univariate and multivariate form. This translation keeps the
statistical computations and removes the R `.Call`/SEXP interface layer.
There is no plotting code in the upstream computational core.

## Requirements

- Fortran 2018 compiler
- FPM (Fortran Package Manager)
- no external numerical libraries

Build and test with:

```text
fpm build
fpm test
fpm run --example example_biasedurn
```

## Public module

Use the umbrella module:

```fortran
use biasedurn
```

`dp` is the package real kind (`kind(1.0d0)`).

## Numerical implementation

Fisher probabilities are normalized in log space. The multivariate Fisher
normalizing constant is computed by dynamic programming on the coefficient
of the generating polynomial rather than by enumerating every composition.
This also provides exact conditional probabilities for random generation.

Wallenius probabilities use the defining integral

```text
prod_i choose(m_i,x_i) * integral_0^1
    prod_i (1 - t**(odds_i/d))**x_i dt,

d = sum_i odds_i * (m_i-x_i).
```

The integral is transformed with `t=exp(-u)`, scaled at its mode, and
calculated by Gauss-Legendre quadrature. This avoids overflow/underflow over
a wide range of odds. Multiplying all multivariate odds by a common constant
has no effect, and the implementation normalizes them internally before
integration.

Wallenius random numbers are generated by the sequential weighted urn
experiment that defines the distribution. Fisher random numbers are drawn
from exact finite-support conditional probabilities.

The inverse routines use the same Cornfield and Manly approximations used by
the R package.

## Example

```fortran
program demo
   use biasedurn
   implicit none
   integer :: x

   x = qwnchypergeo(0.5_dp, 10, 15, 8, 2.5_dp)
   print *, x
   print *, dwnchypergeo(x, 10, 15, 8, 2.5_dp)
end program demo
```
