# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation.
- Added the ordinary numeric single-objective benchmark collection.
- Added DTLZ, ZDT, WFG, MOP, CEC2009 UF, CEC2019 MMF/SYMPART/OMNI, ED,
  and other multi-objective benchmarks.
- Added NK evaluation with flat Fortran storage.
- Added strict GNU Fortran regression scripts, tests, and examples.
