# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of soma 1.2.0.
- Added All To One, T3A and Pareto strategies.
- Added bounds/options/result derived types.
- Added deterministic Fortran seed helper.
- Preserved migration history and evaluation-count bookkeeping.
- Added strict tests for all three strategies and initialization/validation.
- Preserved GPL-2.0-only licensing and upstream source provenance.
