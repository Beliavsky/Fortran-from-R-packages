# Notice

This project translates the computational core of the R package `miscTools`
0.6-30 by Arne Henningsen and Ott Toomet into modern Fortran/FPM.

R graphics, data-frame digest/reporting infrastructure, arbitrary attributes,
and fitted-model S3 dispatch are intentionally outside the scope of the
numerical library. See `API_MAP.md` and `PORTING_NOTES.md`.
