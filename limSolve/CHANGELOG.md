# Changelog

## 0.1.0

- Initial modern Fortran/FPM translation of limSolve 2.0.3 computational API.
- Added generalized inverse, resolution, NNLS, LDP/LDEI/LSEI, LP/ranges,
  structured linear-system solvers, and MCMC feasible-space sampling.
- Vendored prior Fortran translations of lpSolve and quadprog.
- Added strict GNU Fortran regression suite and examples.
