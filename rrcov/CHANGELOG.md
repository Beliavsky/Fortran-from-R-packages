# Changelog

## 0.1.0 - 2026-08-03

- Initial modern Fortran/FPM translation.
- Added self-contained robust covariance/location estimators.
- Added classical and robust PCA, LDA, QDA, Hotelling, and Wilks routines.
- Added robust scales, outlyingness, matrix utilities, examples, tests, and
  checked/optimized build scripts.
- Preserved GPL-3.0-or-later licensing and the upstream source snapshot.
